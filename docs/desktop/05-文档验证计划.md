# 桌面客户端 - 文档验证计划

## 1. 文档说明

### 1.1 文档目的

本文给出从仓库根目录可直接执行的文档审计门禁。验证不止检查 Markdown 文本，还构建桌面工程并运行 C++ 单元测试与 Qt Quick Test，以满足 `[已实现]` 的双证据要求。

### 1.2 权威来源

- DOC-00 的治理、状态与路径规则；
- DOC-01/02/03 的现行合同；
- DOC-04 的实现/测试证据账本；
- DOC-06 的用例映射；
- `clients/desktop/tests/CMakeLists.txt` 的测试注册。

### 1.3 运行前提

- 当前目录为仓库根；
- 已安装 Python 3、CMake、C++23 工具链和 Qt 6 开发包；
- `clients/desktop/build/` 是允许生成的忽略目录，不计入文档变更边界；
- 本次文档任务允许修改的源文件只有 DOC-00 至 DOC-06；
- 命令按 §4 顺序执行，任一 P0/P1 失败都阻止完成审计。

## 2. 严重程度与维度

### 2.1 严重程度

| 级别 | 含义 | 完成要求 |

| P2 | 非阻断建议或超出本任务修改边界的基线债务 | 记录并建立后续修复入口 |

#### CASE-TEST-003（P0）：DOC-04 命名的 Qt Quick Test 全部通过

```bash
python3 - <<'PY'
import os
import re
import subprocess
from collections import defaultdict
from pathlib import Path

doc = Path("docs/desktop/04-组件页面与实现映射.md").read_text(encoding="utf-8")
names = set()
for line in doc.splitlines():
    if "|" not in line or "`[已实现]`" not in line:
        continue
    names.update(re.findall(r"`([A-Za-z_][A-Za-z0-9_]*)`", line.rsplit("|", 2)[-2]))

qml_files = list(Path("clients/desktop/tests/quick").rglob("*.qml"))
groups = defaultdict(set)
for name in names:
    hits = [
        path
        for path in qml_files
        if re.search(
            rf"\bfunction\s+{re.escape(name)}\s*\(",
            path.read_text(encoding="utf-8"),
        )
    ]
    if not hits:
        continue
    assert len(hits) == 1, f"ambiguous QML test {name}: {hits}"
    groups[hits[0]].add(name)

metadata = subprocess.run(
    ["ctest", "--test-dir", "clients/desktop/build", "-N", "-V"],
    check=True,
    text=True,
    capture_output=True,
).stdout
qml_import_match = re.search(r'"-import" "([^"]+)"', metadata)
assert qml_import_match, "cannot resolve Qt QML import path from CTest metadata"

quick = str(Path("clients/desktop/build/tests/desktop-quick-tests").resolve())
env = os.environ.copy()
env["QML_XHR_ALLOW_FILE_READ"] = "1"
env["DESKTOP_QML_EVIDENCE_DIR"] = str(
    Path("clients/desktop/build/tests/qml-evidence").resolve()
)
executed = 0
for path, functions in sorted(groups.items(), key=lambda item: str(item[0])):
    source = path.read_text(encoding="utf-8")
    case_match = re.search(
        r'\bTestCase\s*\{[\s\S]{0,300}?\bname:\s*"([^"]+)"',
        source,
    )
    assert case_match, f"cannot resolve TestCase name: {path}"
    selected = [f"{case_match.group(1)}::{name}" for name in sorted(functions)]
    result = subprocess.run(
        [
            quick,
            "-platform", "offscreen",
            "-input", str(path.resolve()),
            "-import", qml_import_match.group(1),
            "-silent",
            *selected,
        ],
        env=env,
        text=True,
        capture_output=True,
    )
    assert result.returncode == 0, (
        f"{path} failed ({result.returncode}):\n{result.stdout}\n{result.stderr}"
    )
    print(f"PASS {path} ({len(selected)} named tests)")
    executed += len(selected)

assert executed > 0, "no QML evidence tests extracted"
print(f"PASS CASE-TEST-003 ({executed} named QML tests in {len(groups)} files)")
PY
```

Quick 门禁从 CTest 元数据解析 QML import 路径，并复用注册目标的 offscreen 与 XHR 环境。它按文件运行 DOC-04 实际命名的函数，避免未被证据引用的过期源码字符串断言掩盖本次审计结果。
