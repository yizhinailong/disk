## 2. 对象 taxonomy

本节沿用 DOC-01 §6 的五类定义，并补充每类的 QML 文件归属和生命周期规则。此 taxonomy 是后续映射矩阵的分类基线。

### 2.1 五类对象定义

| 类型 | 前缀 | 定义 | 特征 | QML 文件归属 |
|------|------|------|------|-------------|
| 页面 (page) | `PAGE-` | 在 StackView 中独立存在的完整内容区域 | 有自己的 Header 标题和副标题；通过 Sidebar 独立页面入口触发 `stackView.replace()` | `clients/desktop/qml/pages/*.qml` |
| 视图模式 (view mode) | `VIEW-` | 资源管理器上下文内的数据视角，不是独立页面 | 共享 `PAGE-DRIVE` 的三栏布局；切换不触发 StackView 操作；通过 Sidebar 文件视图入口激活 | 嵌入 `DriveBrowserPage.qml` 内部，无独立文件 |
| 面板 (panel) | `COMP-` | 嵌入页面或弹出显示的功能区域，承载特定交互能力 | 不是 StackView 的独立项；生命周期依附于父页面；以 Popup 弹出或固定区域嵌入 | `clients/desktop/qml/components/*.qml`（Popup 类型） |
| 组件 (component) | `COMP-` | 可复用的 UI 元素，嵌入页面/面板中使用 | 不独立导航；通过属性和信号与父级通信 | `clients/desktop/qml/components/*.qml`（非 Popup 类型） |
| 瞬态 UI (transient) | 无统一前缀 | 模态或非模态的临时浮层，不参与导航栈 | 由用户操作触发显示，关闭后回到触发前的状态 | 内联在各页面文件中（Dialog、Toast 等） |

### 2.2 Taxonomy 不变量（继承自 DOC-01 §6.2）

1. `FolderTreePanel` 是面板（`COMP-FOLDERTREE`），不是页面。它以 Popup 形式弹出，嵌入在 `PAGE-DRIVE` 中。
2. `BreadcrumbBar` 是组件（`COMP-BREADCRUMB`），不是页面。它嵌入在 `PAGE-DRIVE` 的内容区内。
3. `PageStateView` 是组件（`COMP-PAGESTATEVIEW`），不是页面。它根据 `pageState` 属性在 loading/empty/content/error 之间切换显示。
4. 五个文件视图模式（`VIEW-*`）不是五个独立页面，而是 `PAGE-DRIVE` 内部的五种数据视角。
5. `PAGE-DRIVE` 是唯一承载文件视图模式的页面。Sidebar 的文件视图入口切换 `PAGE-DRIVE` 内部的数据绑定，不替换 StackView。
