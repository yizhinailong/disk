# 桌面客户端 - 组件、页面与实现映射

## 1. 文档说明

### 1.1 文档目的

本文是 DOC-00 至 DOC-03 状态声明的证据账本：登记当前源码、稳定符号/对象名和可执行测试。它不重复设计细节；规划行为只指向其唯一规范所有者。

### 1.2 权威来源

- DOC-00 的 `[已实现]` / `[待验证]` / `[规划]` 判定规则；
- DOC-01 的 Shell、PAGE、VIEW taxonomy；
- DOC-02/03 的交互、状态和导航合同；
- 当前 `clients/desktop/` 源码与 `clients/desktop/tests/CMakeLists.txt` 注册的测试。

### 1.3 冻结不变量与证据规则

1. `[已实现]` 行必须同时包含实现锚点和可执行测试锚点。
2. QML 锚点使用组件、属性、函数或 `objectName`；C++ 锚点使用类/方法；测试锚点使用测试函数。
3. 源码行号不作为证据，避免组件拆分或格式化后漂移。
4. 只扫描源码文本的 Quick Test 可证明静态接线；涉及状态转换、实例保持和渲染结果的声明还必须有运行时 Quick Test 或 C++ 单元测试。
5. 不存在的规划文件不列为路径；当前表中所有仓库相对路径都必须存在。

## 5. C++ 绑定映射

### 5.1 上下文属性

`clients/desktop/src/app/Application.cpp` 创建并注入以下主要对象；QML 不自行构造网络业务层：

| QML 上下文职责 | C++ 类型 | 主要消费者 |
|---|---|---|
| Shell 路由 | `ShellController` | Main、全部 Shell |
| 会话聚合 | `SessionStore` | ShellController、Visitor/Owner 流 |
| 认证操作 | `AuthService` | Login、Register、Owner logout |
| 文件操作 | `DriveManager` | DriveBrowserPage / VIEW-MYFILES |
| 分享管理 | `ShareManager` | VIEW-SHARED、分享 Dialog |
| 回收站 | `TrashManager` | VIEW-TRASH |
| 传输 | `TransferManager` | PAGE-DRIVE、PAGE-TRANSFER、Visitor 下载 |
| 资料 | `ProfileManager` | PAGE-SETTINGS |
| 网络设置/健康 | `NetworkSettingsManager`、`HealthManager` | PAGE-SETTINGS、Admin 状态 |
| 管理员 | `AdminManager` | AdminPage 四个目的地 |
