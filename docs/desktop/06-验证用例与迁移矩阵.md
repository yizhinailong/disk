# 桌面客户端 — 验证用例与迁移矩阵

## 1. 文档说明

### 1.1 文档目的

本文档包含两部分内容：

1. **验证用例清单**：`CASE-` 级验证用例，覆盖新文档系列的结构、术语、交叉引用、实现锚点和状态标签完整性，可直接用于最终波次的验证执行。
2. **迁移矩阵**：旧文档系列（7 个文件）到新系列的逐项映射，以及归档到 `docs/desktop/legacy/` 的最终处置记录。

### 1.2 权威来源

| 来源 | 路径 | 用途 |
|------|------|------|
| 文档治理基线 | `docs/desktop/00-桌面客户端系统概述与文档治理.md` | 权威层级、旧文档处置策略 |
| 文档验证计划 | `docs/desktop/05-文档验证计划.md` | 验证维度、失败口径、V1-V8 编号体系 |
| 组件页面与实现映射 | `docs/desktop/04-组件页面与实现映射.md` | 实现锚点、状态标签、测试证据基线 |
| 后端单元测试用例（参考） | `docs/design/06-单元测试用例.md` | 用例统计与状态表的呈现方式 |

### 1.3 冻结不变量

1. 所有旧文件（7 个）都必须在迁移矩阵中出现，不能遗漏。
2. 旧文件的最终归宿是 `docs/desktop/legacy/`，不得与新系列并列在 `docs/desktop/` 根目录。
3. `final-report-zh.md` 归档后只能以历史身份被引用，不再出现在活动规范引用链中。
4. 活动新系列文档（00-06）不得引用 `docs/desktop/` 根目录下的旧文件路径作为规范来源。
