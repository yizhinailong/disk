## 1. 文档说明

### 1.1 文档目的

本文登记 DOC-05 的全部强制用例、2026-07-19 实现重审映射，以及退役旧文档到当前核心系列的迁移记录。命令正文只在 DOC-05 维护，本文不复制脚本。

### 1.2 权威来源

- DOC-00 的文档治理和状态规则；
- DOC-01/02/03 的现行产品合同；
- DOC-04 的实现/测试证据账本；
- DOC-05 的命令、严重程度和执行顺序；
- Git 历史中 commit `ebb931b` 的旧文档删除记录。

### 1.3 冻结不变量

1. CASE ID、严重程度和数量必须与 DOC-05 一致。
2. 本文只映射验证意图，不维护第二份命令实现。
3. 退役文件只写 basename，不伪造当前路径或 `legacy/` 目录。
4. 当前实现证据使用完整仓库相对路径和测试函数，不使用源码行号。
5. 规划行为只指向 DOC-02/03 的唯一规范位置，不复制完成标准。
