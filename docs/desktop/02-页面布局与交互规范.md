# 桌面客户端 — 页面布局与交互规范

## 1. 文档说明

### 1.1 文档目的

本文档定义桌面客户端资源管理器主页的三栏布局规范和逐项交互矩阵。每个交互条目都标注 `已实现 / 规划 / 待验证` 状态标签（标签定义见 DOC-00 §5.2），使当前实现与目标规范之间的差异透明可追踪。本文档为 DOC-03（状态与导航）和 DOC-04（组件与实现映射）提供布局和交互层面的唯一基线。

### 1.2 权威来源

| 来源 | 路径 | 用途 |
|------|------|------|
| 文档治理基线 | `docs/desktop/00-桌面客户端系统概述与文档治理.md` | 权威层级、状态标签定义、资源管理器模型 |
| 信息架构与功能视图 | `docs/desktop/01-信息架构与功能视图.md` | 视图模式 taxonomy、Shell 架构、五类对象分类 |
| 当前实现锚点 | `clients/desktop/qml/shells/OwnerShell.qml` | Shell 层 Header + Sidebar + StackView 结构 |
| 当前实现锚点 | `clients/desktop/qml/pages/DriveBrowserPage.qml` | 文件浏览页：工具栏、面包屑、列表视图、对话框 |
| 当前实现锚点 | `clients/desktop/qml/components/FolderTreePanel.qml` | 目录树面板组件（Popup 弹出，非常驻） |
| 当前实现锚点 | `clients/desktop/qml/components/BreadcrumbBar.qml` | 面包屑导航组件 |
| 历史输入 | `docs/desktop/legacy/04-navigation-and-ui-state.md` | 旧动作矩阵和页面状态定义，仅作迁移输入 |

### 1.3 冻结不变量

1. 资源管理器主页采用三栏布局：固定 Header + Sidebar + 主内容区 + 可选状态栏。三个文件视图模式（VIEW-MYFILES、VIEW-SHARED、VIEW-TRASH）共享此布局框架（DOC-00 §3.1，DOC-01 §3.1）。
2. 每项交互必须标注状态标签，不得把未实现能力写成已实现事实（DOC-00 §5.2 防误写规则）。
3. 右键上下文菜单、拖拽操作、多选框选、网格视图模式当前无成型实现证据，必须标注为 `规划` 或 `待验证`。
4. 文件夹钻取采用同页切换 `currentFolderId` 的方式，不使用 `StackView push` 新页面。此行为已被 quick test 验证（`tst_drive_browser_navigation.qml`）。
5. 导航和状态机的具体规则（选择模型、页面状态迁移、路由守卫）由 DOC-03 定义，本文档仅规定布局和交互触发的行为契约。

## 2. 三栏布局规范

资源管理器主页（`PAGE-DRIVE`）在 Owner Shell 内部呈现为三栏布局。Owner Shell 顶层为 `ApplicationWindow`，内部通过 `RowLayout` 分为左侧 Sidebar 和右侧内容区；右侧内容区上方是固定 Header，下方是 `StackView` 承载的页面内容。

### 2.1 Header（Shell 层固定顶部栏）

Header 在 Owner Shell 层定义，所有页面共享，不随视图模式切换而改变结构。

| 元素 | 说明 | 状态 |
|------|------|------|
| 页面标题 | 显示当前页面/视图名称（如 "文件"、"传输"），由 `currentPageTitle` 驱动 | `[已实现]` OwnerShell.qml `destinationTitle()` |
| 页面副标题 | 显示当前页面简要描述（如 "浏览和管理您的网盘"），由 `currentPageSubtitle` 驱动 | `[已实现]` OwnerShell.qml `destinationSubtitle()` |
| 用户信息卡片 | 右上角固定卡片，显示 `nickname / username`，84px 固定高度 | `[已实现]` OwnerShell.qml 右侧 Rectangle |
| 底部分割线 | Header 底部 1px 实线分割 | `[已实现]` OwnerShell.qml |
| 搜索框 | Header 内嵌入搜索输入框，触发文件搜索 | `[规划]` 当前 Header 无搜索框，搜索功能属于 O-07 |

### 2.2 Sidebar（左侧导航栏）

Sidebar 在 Owner Shell 层定义，固定可见，宽度 220px，背景色与主内容区区分。

| 元素 | 说明 | 状态 |
|------|------|------|
| 品牌区 | 顶部卡片，显示 "Disk" + "工作空间"，104px 高度 | `[已实现]` OwnerShell.qml 品牌卡片 |
| 导航区 | 按钮列表，支持 hover 和 active 状态（背景色 + 左侧 4px 条纹指示） | `[已实现]` OwnerShell.qml 导航按钮 |
| 存储统计卡片 | 底部固定卡片，显示已用/总量文字和 ProgressBar，标题 "存储空间"，104px 高度 | `[已实现]` OwnerShell.qml Storage 卡片 |
| 会话区 | 退出登录按钮，红色调文字，hover 变色 | `[已实现]` OwnerShell.qml 退出登录按钮 |

#### 2.2.1 当前导航入口 vs 目标导航入口

当前 Sidebar 包含 2 组导航：文件视图模式组（我的文件、分享、回收站）和独立页面组（传输、设置）。各入口通过 `showDriveViewMode()` 或 `stackView.replace()` 切换。

| 当前入口 | 目标归属 | 切换行为 | 状态 |
|----------|---------|---------|------|
| Files | VIEW-MYFILES（视图模式） | 不替换 StackView，切换 `PAGE-DRIVE` 数据源 | `[待验证]` 当前仍为 `stackView.replace()` |
| Transfers | PAGE-TRANSFER（独立页面） | `stackView.replace()` 切换页面 | `[已实现]` |
| Shares | VIEW-SHARED（视图模式） | 不替换 StackView，切换 `PAGE-DRIVE` 数据源 | `[待验证]` 当前仍为独立页面替换 |
| Trash | VIEW-TRASH（视图模式） | 不替换 StackView，切换 `PAGE-DRIVE` 数据源 | `[待验证]` 当前仍为独立页面替换 |
| Settings | PAGE-SETTINGS（独立页面） | `stackView.replace()` 切换页面 | `[已实现]` |

详细的实现差距分析见 DOC-01 §2.1.2。

#### 2.2.2 Sidebar 交互规范

| 交互 | 行为 | 状态 |
|------|------|------|
| 悬浮导航按钮 | 背景色变为 hover 色（`#eef2f6`），无左侧条纹 | `[已实现]` |
| 点击独立页面入口 | `stackView.replace()` 切换页面，Header 标题/副标题同步更新，active 状态高亮（背景色 + 左侧条纹） | `[已实现]` |
| 点击视图模式入口 | 在 `PAGE-DRIVE` 内切换数据源，不替换 StackView，Header 标题/副标题联动 | `[规划]` 当前仍为页面替换行为 |
| 视图模式切换清空状态 | 清空选中项、面包屑（如适用）、当前加载的数据 | `[规划]` |
| 点击登出按钮 | 调用 `sessionStore.owner.StartLogout()`，清理会话 | `[已实现]` |

## 3. 交互矩阵

### 3.1 单击（Click）

| 交互场景 | 行为 | 状态 |
|----------|------|------|
| 单击文件/文件夹行 | 选中该项目（设置 `selectedItemId` / `selectedItemKind` / `selectedItemName`），高亮该行，其他行取消高亮 | `[已实现]` `onClicked: root.selectItem(...)` |
| 单击面包屑节点 | 导航到对应目录（同页切换 `currentFolderId`），触发 tree + list + breadcrumb 三路刷新 | `[已实现]` `onPathClicked` 信号 |
| 单击目录树节点 | 导航到对应目录，同步更新面包屑和文件列表 | `[已实现]` `FolderTreePanel.onFolderClicked` 信号 |
| 单击 "打开" 按钮 | 导航到该文件夹（同页切换），与面包屑导航行为一致 | `[已实现]` `onClicked: root.navigateToFolder(model.id)` |
| 单击上级按钮 | 导航到上级目录（面包屑倒数第二项），根目录时按钮 disabled | `[已实现]` quick test 已验证 |
| 单击刷新按钮 | 清空选中项，重新加载 tree + list + breadcrumb | `[已实现]` `refreshCurrentFolder()` |
| 单击空白区域 | 取消选中项（清空 `selectedItemId` 等） | `[规划]` 当前 `ListView` 不处理空白区域点击 |
| 单击工具栏按钮 | 触发对应操作（上传、下载、新建文件夹等），详见 §2.3.1 | `[已实现]` |

### 3.2 双击（Double Click）

| 交互场景 | 行为 | 状态 |
|----------|------|------|
| 双击文件夹行 | 导航到该文件夹（同页切换 `currentFolderId`），等同于单击打开按钮 | `[规划]` 当前 `ItemDelegate` 仅有 `onClicked`，无双击处理。文件夹导航通过显式打开按钮实现 |
| 双击文件行 | 打开文件详情或触发下载 | `[规划]` 当前无此交互 |

> **实现现状说明**：`DriveBrowserPage.qml` 的列表行 delegate 使用 `onClicked` 处理单击选中。文件夹导航通过行内 "打开" 按钮触发，而非双击。`tst_drive_browser_navigation.qml` 验证的是 `navigateToFolder()` 行为，不涉及双击 UI 触发路径。因此双击文件夹导航必须标注为 `[规划]`。

### 3.3 右键（Right Click）

| 交互场景 | 行为 | 状态 |
|----------|------|------|
| 右键文件/文件夹行 | 弹出上下文菜单，包含：打开、下载、重命名、移动、复制、删除、创建分享等操作 | `[规划]` 当前无右键菜单实现，所有操作通过工具栏按钮触发 |
| 右键空白区域 | 弹出上下文菜单，包含：上传文件、新建文件夹、粘贴、刷新、排序等操作 | `[规划]` 当前无空白区域右键菜单 |
| 右键面包屑节点 | 弹出上下文菜单，包含：在新标签页打开、复制路径等 | `[规划]` |

### 3.4 拖拽（Drag and Drop）

| 交互场景 | 行为 | 状态 |
|----------|------|------|
| 拖拽文件到文件夹行 | 将被拖拽文件/文件夹移动到目标文件夹 | `[规划]` 当前无拖拽处理，移动操作通过工具栏按钮触发 |
| 拖拽文件到空白区域 | 取消拖拽操作 | `[规划]` |
| 拖拽文件到目录树节点 | 将被拖拽文件/文件夹移动到目标目录树节点 | `[规划]` |
| 从外部拖拽文件到窗口 | 触发文件上传到当前目录 | `[规划]` DOC-00 §6.3 明确排除"拖拽上传"于首版范围之外，但窗口内拖拽移动可纳入后续规划 |

### 3.5 多选（Multi-Select）

| 交互场景 | 行为 | 状态 |
|----------|------|------|
| Ctrl + 单击 | 切换单个项目的选中状态（追加或移除），不影响已选中项 | `[规划]` 当前仅支持单选（`selectedItemId` 单值属性） |
| Shift + 单击 | 选中从上次单击项到当前项之间的所有连续项目 | `[规划]` 当前无多选模型 |
| 鼠标框选 | 在空白区域按住左键拖拽绘制选择框，框内项目全部选中 | `[规划]` 当前无框选实现 |
| Ctrl + A | 全选当前列表所有项目 | `[规划]` |
| 点击已选中项 | 取消该项选中（如 Ctrl 不按住则清空其他选中项） | `[规划]` |

> **实现现状说明**：当前 `DriveBrowserPage` 的选择模型是单值属性（`selectedItemId` / `selectedItemKind` / `selectedItemName`），每次 `selectItem()` 调用会覆盖之前的选中项。多选需要引入集合类型的选择模型，属于架构级变更。

### 3.6 悬浮（Hover）

| 交互场景 | 行为 | 状态 |
|----------|------|------|
| 悬浮文件/文件夹行 | 非选中行背景从透明变为白色（`hoverEnabled: true`），提供视觉反馈 | `[已实现]` ItemDelegate `hoverEnabled: true` |
| 悬浮截断的文件名 | 文件名被截断且鼠标悬浮时，350ms 延迟后显示 tooltip，5000ms 超时 | `[已实现]` `ToolTip.visible: truncated && fileRowDelegate.hovered` |
| 悬浮 Sidebar 按钮 | 背景色变为 hover 色，非 active 时无左侧条纹 | `[已实现]` OwnerShell 导航按钮 `hoverEnabled: true` |
| 悬浮目录树节点 | 节点背景变为 hover 色 | `[已实现]` FolderTreePanel `rowMouseArea.hoverEnabled: true` |
| 悬浮目录树截断名称 | 截断的文件夹名悬浮时显示 tooltip | `[已实现]` FolderTreePanel `ToolTip` |
| 悬浮操作按钮 | 按钮外观变化提供可点击反馈 | `[待验证]` Qt 默认按钮 hover 样式，未定制 |

### 3.7 加载反馈（Loading Feedback）

| 反馈类型 | 触发场景 | 展示方式 | 状态 |
|----------|---------|---------|------|
| 页面状态切换 | 文件夹导航、刷新、首次加载 | `PageStateView` 组件根据 `shellController.pageState` 在 loading / empty / content / error 之间切换显示 | `[已实现]` loading 态隐藏内容面板 |
| 状态芯片 | 文件夹加载中 | 状态摘要卡片右侧芯片显示 "正在刷新" | `[已实现]` `pageStateLabel()` |
| 状态摘要文字 | 文件夹加载中 | 摘要卡片显示 "正在刷新文件夹内容和网盘导航" | `[已实现]` `driveStatusSummary()` |
| 骨架屏（skeleton） | 初始加载时模拟列表布局的灰色占位块 | 以动画灰色矩形代替真实列表行，提供视觉稳定性 | `[规划]` 当前 loading 态仅隐藏内容区，无骨架屏 |
| 上传进度条 | 文件上传中 | 传输中心展示每个上传任务的进度条、速度、剩余时间 | `[已实现]` `PAGE-TRANSFER` 中展示 |
| 下载进度条 | 文件下载中 | 传输中心展示每个下载任务的进度条、速度、剩余时间 | `[已实现]` `PAGE-TRANSFER` 中展示 |
| 操作进行中反馈 | 创建文件夹/重命名/删除请求已发送 | 按钮文字变为 "创建中..." / "保存中..." / "删除中..."，表单输入和按钮 disabled | `[已实现]` `mutationInFlight` 状态控制 |
| Toast 通知 | 操作成功/失败的轻量提示 | 页面底部短暂浮现的条状通知，3 秒自动消失（`toastOverlay` + `toastDismissTimer`） | `[已实现]` `showToast()` / `hideToast()`，Rectangle + Label + Timer 实现 |

## 4. 失败提示规范

### 4.1 内联错误（Inline Error）

内联错误显示在触发操作的区域附近，不阻断用户的其他操作。

| 触发场景 | 展示方式 | 状态 |
|----------|---------|------|
| 上传失败 | 工具栏下方红色文字，`uploadErrorMessage` 驱动 | `[已实现]` |
| 下载失败 | 工具栏下方红色文字，`downloadErrorMessage` 驱动 | `[已实现]` |
| 新建文件夹验证失败 | 对话框内红色文字（名称不合法），输入框保持焦点 | `[已实现]` `createFolderErrorMessage` |
| 重命名验证失败 | 对话框内红色文字（名称不合法），输入框保持焦点 | `[已实现]` `renameErrorMessage` |
| 删除失败 | 对话框内红色文字（如 "此版本不支持删除文件夹"） | `[已实现]` `deleteErrorMessage` |
| 文件夹加载失败 | 内容区显示 "加载文件夹内容失败" + 重试按钮，由 `PageStateView` error 态渲染 | `[已实现]` |

### 4.2 模态对话框（Modal Dialog）

模态对话框用于需要用户确认或输入的操作，阻断页面其他交互。

| 触发场景 | 展示方式 | 状态 |
|----------|---------|------|
| 新建文件夹 | 模态 Dialog，标题 "新建文件夹"，包含输入框、取消 / 创建 按钮、内联错误提示，请求中禁用输入和按钮 | `[已实现]` `newFolderDialog`，`closePolicy: NoAutoClose` |
| 重命名 | 模态 Dialog，标题 "重命名"，包含预填名称的输入框、取消 / 保存 按钮、内联错误提示 | `[已实现]` `renameDialog` |
| 删除确认 | 模态 Dialog，标题 "删除"，包含确认文字、取消 / 删除 按钮、内联错误提示 | `[已实现]` `deleteDialog` |
| 文件选择（上传） | 原生 `Platform.FileDialog`，OpenFile 模式，选择后触发上传 | `[已实现]` `uploadFileDialogComponent` |
| 文件选择（下载） | 原生 `Platform.FileDialog`，SaveFile 模式，选择后触发下载 | `[已实现]` `downloadFileDialogComponent` |
| 移动/复制目标选择 | 模态 Dialog，展示目录树供用户选择目标文件夹 | `[规划]` 当前移动/复制操作未实现 UI 入口 |
| 批量操作结果展示 | 模态 Dialog，逐项展示批量操作结果（成功/失败） | `[规划]` 当前仅支持单选操作 |

### 4.3 Toast 通知（Toast Notification）

Toast 通知用于短暂的操作成功/失败反馈，不阻断用户操作。

| 触发场景 | 展示方式 | 状态 |
|----------|---------|------|
| 操作成功 | 页面底部条状通知，3 秒自动消失（如 "文件夹已创建"） | `[已实现]` `showToast()` 触发 `toastOverlay` |
| 操作部分失败 | 条状通知带展开详情按钮（如 "3/5 项已删除，2 项失败"） | `[规划]` |
| 认证状态变更 | 条状通知提示令牌刷新或会话过期 | `[规划]` |

## 5. 进度与骨架屏规范

### 5.1 进度条

| 进度条类型 | 位置 | 展示内容 | 状态 |
|-----------|------|---------|------|
| 上传任务进度 | `PAGE-TRANSFER` 中 | 文件名、进度百分比/进度条、速度、剩余时间、操作按钮（暂停/继续/取消/重试） | `[已实现]` `transferManager.uploadModel` |
| 下载任务进度 | `PAGE-TRANSFER` 中 | 文件名、进度百分比/进度条、速度、剩余时间、操作按钮（暂停/继续/取消/重试） | `[已实现]` `transferManager.downloadModel` |
| 存储空间进度 | Sidebar 存储统计卡片 | 已用/总量的 ProgressBar，百分比文字 | `[已实现]` OwnerShell `ProgressBar` |
| 操作进行中指示 | Dialog 按钮文字 | 按钮文字变为 "创建中..." / "保存中..." / "删除中..." | `[已实现]` |

### 5.2 骨架屏（Skeleton Screen）

| 场景 | 展示方式 | 状态 |
|------|---------|------|
| 首次加载文件夹 | 以灰色动画矩形模拟列表行的文件名、类型、大小、时间列 | `[规划]` 当前 loading 态仅通过 `PageStateView` 隐藏内容区，无骨架屏动画 |
| 搜索加载中 | 搜索结果区域骨架屏 | `[规划]` |
| 视图模式切换加载 | 主内容区短暂骨架屏（数据源切换时） | `[规划]` |

### 5.3 加载状态层次

当多个加载反馈同时适用时，按以下优先级展示：

| 优先级 | 反馈类型 | 触发条件 |
|--------|---------|---------|
| 1 | 模态 Dialog 中的操作进行中指示 | `mutationInFlight === true` 且对话框打开 |
| 2 | 内容区 PageStateView loading 态 | `shellController.pageState === "loading"` |
| 3 | 状态芯片 "正在刷新" | 同上，芯片始终反映 pageState |
| 4 | 骨架屏（规划） | 初始加载或视图模式切换时，替代空白 loading 态 |
