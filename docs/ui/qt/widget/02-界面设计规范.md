# Disk Qt Widget 桌面客户端 - 界面设计规范

## 1. 设计概述

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **平台原生感** | 遵循各平台设计规范（Windows/macOS/Linux），使用 QWidget 原生控件 |
| **简洁直观** | 信息层次清晰，操作路径简短 |
| **一致性** | 统一的视觉语言和交互模式，通过 QStyleSheet 实现统一样式 |
| **响应式** | 窗口大小自适应，支持高分屏，使用 QLayout 进行弹性布局 |
| **可访问性** | 支持键盘导航，高对比度模式，QWidget 原生无障碍支持 |

### 1.2 目标用户特征

| 用户类型 | 特征 | 设计考量 |
|----------|------|----------|
| **普通用户** | 偶尔使用，需要引导 | 提供直观的图标和提示，简化 QToolBar 操作 |
| **办公用户** | 频繁使用，追求效率 | 支持快捷键和批量操作，优化 QTreeView 交互 |
| **专业用户** | 大量文件管理 | 提供高级搜索和过滤功能，利用 QSortFilterProxyModel |

### 1.3 技术架构概述

本客户端基于 **Qt Widgets** 技术栈构建：

| 技术组件 | 说明 |
|----------|------|
| QWidget | 所有 UI 控件的基类 |
| QStyleSheet | 类似 CSS 的样式表系统，用于统一定义外观 |
| QLayout | 布局管理器，负责控件的自动排列和大小调整 |
| QMainWindow | 主窗口框架，包含菜单栏、工具栏、状态栏 |
| QStyle | 平台原生样式，可自定义绘制 |

void TransferPanel::togglePanel() {
    QPropertyAnimation* animation = new QPropertyAnimation(this, "maximumHeight");
    animation->setDuration(200);
    animation->setEasingCurve(QEasingCurve::InOutQuad);
    
    if (m_expanded) {

## 9. 国际化

### 9.1 支持语言

| 语言 | 代码 | Qt 翻译文件 |

| 简体中文 | zh_CN | `disk_zh_CN.qm` |
| English | en_US | `disk_en_US.qm` |

### 9.2 Qt 国际化实现

```cpp
// main.cpp
int main(int argc, char* argv[]) {
    QApplication app(argc, argv);
    
    // 加载翻译
    QTranslator translator;
    QString locale = QLocale::system().name();
    if (translator.load(":/translations/disk_" + locale + ".qm")) {
        app.installTranslator(&translator);
    }
    
    MainWindow window;
    window.show();
    
    return app.exec();
}

// 在代码中使用 tr() 函数
QPushButton* button = new QPushButton(tr("上传文件"));
QLabel* label = new QLabel(tr("文件名"));
```

## 10. 布局管理详解

### 10.1 QVBoxLayout (垂直布局)

```cpp
QVBoxLayout* vLayout = new QVBoxLayout();
vLayout->setSpacing(16);  // 控件间距
vLayout->setContentsMargins(16, 16, 16, 16);  // 边距

// 添加控件
vLayout->addWidget(headerLabel);
vLayout->addWidget(contentWidget, 1);  // stretch = 1
vLayout->addWidget(footerWidget);

// 添加弹性空间
vLayout->addStretch();
```

### 10.2 QHBoxLayout (水平布局)

```cpp
QHBoxLayout* hLayout = new QHBoxLayout();
hLayout->setSpacing(8);

// 添加控件
hLayout->addWidget(iconLabel);
hLayout->addWidget(textLabel, 1);  // stretch = 1

// 添加弹性空间
hLayout->addStretch();

hLayout->addWidget(okButton);
hLayout->addWidget(cancelButton);
```

### 10.3 QGridLayout (网格布局)

```cpp
QGridLayout* gridLayout = new QGridLayout();
gridLayout->setSpacing(16);
gridLayout->setHorizontalSpacing(16);
gridLayout->setVerticalSpacing(8);

// 添加控件到网格
gridLayout->addWidget(nameLabel, 0, 0);
gridLayout->addWidget(nameEdit, 0, 1);
gridLayout->addWidget(sizeLabel, 1, 0);
gridLayout->addWidget(sizeValue, 1, 1);

// 设置列拉伸因子
gridLayout->setColumnStretch(0, 0);  // 标签列不拉伸
gridLayout->setColumnStretch(1, 1);  // 内容列拉伸
```

### 10.4 QStackedLayout (堆叠布局)

```cpp
QStackedLayout* stackedLayout = new QStackedLayout();

// 添加页面
stackedLayout->addWidget(loginPage);     // index 0
stackedLayout->addWidget(mainPage);      // index 1
stackedLayout->addWidget(settingsPage);  // index 2

// 切换页面
stackedLayout->setCurrentIndex(1);
// 或
stackedLayout->setCurrentWidget(mainPage);
```
