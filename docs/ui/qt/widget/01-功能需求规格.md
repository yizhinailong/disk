# Disk 桌面客户端 (Qt Widget) - 功能需求规格

## 1. 文档说明

### 1.1 文档目的

本文档详细描述 Disk 网盘系统 Qt Widget 桌面客户端的功能需求规格，作为客户端设计和开发的依据。

### 1.2 技术实现概述

本文档描述的客户端基于 Qt Widgets 框架实现，核心技术选型如下：

| 技术领域 | 技术选型 | 说明 |
|----------|----------|------|
| UI 框架 | Qt Widgets | 传统 Qt 控件体系 |
| 布局管理 | QLayout 系列 | QVBoxLayout、QHBoxLayout、QGridLayout 等 |
| 样式系统 | QStyleSheet | 类 CSS 样式表 |
| 事件处理 | 信号槽机制 | QObject::connect 连接信号与槽 |
| 模型视图 | QAbstractItemModel | 用于列表、树形视图的数据绑定 |
| 网络通信 | QNetworkAccessManager | HTTP 请求处理 |
| 文件操作 | QFile、QDir | 本地文件系统操作 |
| 多媒体 | Qt Multimedia | 音视频播放支持 |
| 数据序列化 | QJsonDocument | JSON 解析与生成 |
| 配置存储 | QSettings | 应用配置持久化 |
| 国际化 | QTranslator | 多语言支持 |

### 1.3 需求优先级说明

| 优先级 | 标识 | 说明 |
|--------|------|------|
| 高 | P0 | 核心功能，必须实现 |
| 中 | P1 | 重要功能，应该实现 |
| 低 | P2 | 增强功能，可选实现 |

### 1.4 功能范围

**包含功能**：
- 认证模块（登录、令牌刷新、登出）
- 文件浏览模块（列表/网格视图）
- 文件预览模块（图片、视频、PDF）
- 文件传输模块（上传、下载）
- 文件操作模块（重命名、移动、复制、删除）
- 文件夹管理模块
- 回收站模块
- 分享模块
- 文件搜索
- 系统模块（托盘、通知、设置）

**不包含功能**：
- 用户注册（桌面客户端仅支持登录，注册需通过 Web 端完成）
- 文件在线编辑（当前版本不支持在线编辑功能）

## 2. 认证模块 [P0]

### 2.1 用户登录

#### 2.1.1 功能描述

用户通过用户名/邮箱和密码进行身份验证，获取访问令牌并进入主界面。

#### 2.1.2 输入参数

| 参数名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| account | string | 是 | 非空 | 用户名或邮箱 |
| password | string | 是 | 非空 | 密码 |
| remember | boolean | 否 | - | 记住密码 |

#### 2.1.3 业务规则

1. 支持用户名或邮箱登录
2. 登录成功后安全存储 `access_token` 和 `refresh_token`
3. Access Token 有效期 2 小时，Refresh Token 有效期 7 天
4. 登录成功后自动跳转到文件列表界面
5. 「记住密码」功能安全存储登录凭证

#### 2.1.4 异常处理

| 错误场景 | 错误码 | 用户提示 |
|----------|--------|----------|
| 用户不存在 | 40100 | 用户不存在 |
| 密码错误 | 40101 | 用户名或密码错误 |
| 账户被锁定 | 40102 | 账户已锁定，请稍后重试 |
| 网络错误 | - | 网络连接失败，请检查网络 |
| 服务不可用 | - | 服务暂时不可用，请稍后重试 |

#### 2.1.5 UI 交互

- 登录窗口居中显示（QDialog 居中）
- 支持密码显示/隐藏切换（QLineEdit::EchoMode 切换）
- 支持回车键快捷登录（连接 QLineEdit::returnPressed 信号）
- 登录中显示加载动画（QMovie + QLabel 或 QProgressIndicator）

#### 2.1.6 Widget 技术实现

### 2.2 令牌刷新

#### 2.2.1 功能描述

当 Access Token 过期时，使用 Refresh Token 自动获取新的 Access Token，实现无感刷新。

#### 2.2.2 触发条件

1. API 请求返回 `40108 TokenExpired` 错误
2. 客户端检测到 Access Token 即将过期（剩余时间 < 5 分钟）

#### 2.2.3 业务规则

1. 使用 Refresh Token 调用 `/api/auth/refresh` 获取新令牌
2. 刷新成功后更新本地存储的令牌
3. 刷新失败（Refresh Token 过期）则跳转到登录界面
4. 令牌刷新对用户透明，不中断当前操作

#### 2.2.4 Widget 技术实现

```cpp
// 令牌管理器
class TokenManager : public QObject {
    Q_OBJECT
public:
    static TokenManager* Instance();
    
    auto GetValidToken() -> QString;  // 返回有效的 access_token
    auto RefreshToken() -> bool;      // 刷新令牌
    
signals:
    void TokenExpired();              // 令牌过期信号
    void RefreshFailed();             // 刷新失败信号
    
private:
    QTimer* m_refreshTimer;           // 定时检查刷新
    QString m_accessToken;
    QString m_refreshToken;
};
```

### 2.3 用户登出

#### 2.3.1 功能描述

用户主动登出，清除本地凭证并使服务端令牌失效。

#### 2.3.2 业务规则

1. 调用 `/api/auth/logout` 使服务端令牌失效
2. 清除本地存储的所有凭证
3. 清除用户缓存数据
4. 返回登录界面
5. 即使服务端登出失败，仍清除本地凭证

#### 2.3.3 Widget 技术实现

```cpp
// 登出处理
void MainWindow::OnLogout() {
    // 1. 发送登出请求（异步）
    m_apiClient->Logout();
    
    // 2. 清除本地数据
    TokenManager::Instance()->ClearTokens();
    QSettings settings;
    settings.remove("userData");
    
    // 3. 清理缓存
    m_fileModel->Clear();
    
    // 4. 显示登录界面
    ShowLoginDialog();
}
```

## 3. 文件浏览模块 [P0]

### 3.1 文件列表

#### 3.1.1 功能描述

展示当前目录下的文件和文件夹列表，支持网格视图和列表视图切换。

#### 3.1.2 视图模式

| 模式 | 说明 |
|------|------|
| 网格视图 | 图标+文件名，适合图片浏览 |
| 列表视图 | 详细信息（名称、大小、修改时间），适合文件管理 |

| type | string | - | ✓ | 文件类型 |

#### 3.1.4 业务规则

1. 文件和文件夹混合显示，通过图标区分
2. 文件夹显示在顶部（可配置）
3. 支持按名称/大小/修改时间/类型排序
4. 支持升序/降序切换

- 双击文件夹进入
- 双击文件下载/预览

- 拖拽文件进行移动

## 5. 文件传输模块 [P0]

### 5.1 文件上传

#### 5.1.1 功能描述

支持本地文件上传到网盘，包括分片上传、秒传和断点续传。

#### 5.1.2 上传流程

```
┌─────────────────────────────────────────────────────────────┐
│                      文件上传流程                            │
├─────────────────────────────────────────────────────────────┤
│  1. 选择文件                                                 │
│     用户通过文件选择器选择本地文件（支持多选）                  │
│                                                              │
│  2. 计算文件哈希                                             │
│     客户端计算文件 MD5 哈希值（后台线程）                      │
│                                                              │
│  3. 初始化上传                                               │
│     调用 /api/file/upload/init，检测秒传/续传                 │
│                                                              │
│  4. 分片上传（非秒传）                                        │
│     将文件分割为 5MB 分片，逐个上传                           │
│                                                              │
│  5. 完成上传                                                 │
│     调用完成接口，服务端合并分片                              │
└─────────────────────────────────────────────────────────────┘
```

#### 5.1.3 上传方式

| 方式 | 说明 |
|------|------|
| 工具栏按钮 | 点击「上传」按钮选择文件 |
| 拖拽上传 | 拖拽文件到窗口上传 |
| 右键菜单 | 右键空白区域选择「上传」 |
| 粘贴上传 | Ctrl+V 粘贴剪贴板图片/文件 |

#### 5.1.4 业务规则

1. **秒传检测**：初始化时服务端检测文件哈希，如已存在则直接完成
2. **断点续传**：检测未完成的上传任务，从断点处继续
3. **并发控制**：同时上传文件数限制（默认 3 个）
4. **存储空间检查**：上传前检查用户存储配额
5. **文件名冲突**：自动重命名（添加后缀）

#### 5.1.5 Widget 技术实现

        return true;
    }
    
    QMessageBox msgBox(this);
    msgBox.setIcon(QMessageBox::Question);
    msgBox.setWindowTitle(tr("确认删除"));
    msgBox.setText(tr("确定要将选中的 %1 个项目移入回收站吗？").arg(fileCount));

    int result = msgBox.exec();
    
    if (dontAskAgain->isChecked()) {
        QSettings().setValue("confirmDelete", false);
    }
    
    return result == QMessageBox::Yes;
