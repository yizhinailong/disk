# Disk 桌面客户端 (Qt Widget) - 架构设计

## 1. 设计概述

### 1.1 设计目标

本文档定义 Qt Widget 桌面客户端的架构设计，主要目标包括：

1. **清晰的分层架构** - 表现层、控制层、模型层职责分明
2. **MVC 模式** - Model-View-Controller 架构，通过信号槽机制实现数据驱动 UI
3. **可测试性** - 依赖注入，便于单元测试和集成测试
4. **可扩展性** - 模块化设计，功能可插拔
5. **跨平台兼容** - 抽象平台相关代码，支持 Windows/Linux/macOS
6. **原生体验** - 充分利用 Qt Widget 的原生外观和性能优势

### 1.2 架构原则

| 原则 | 说明 |
|------|------|
| **单一职责** | 每个类只负责一个功能，Model 管数据、View 管显示、Controller 管逻辑 |
| **依赖倒置** | 高层模块不依赖低层模块，都依赖抽象接口 |
| **接口隔离** | 使用小而专注的接口，避免臃肿的类设计 |
| **开闭原则** | 对扩展开放，对修改关闭，通过继承和多态实现扩展 |
| **信号槽解耦** | 使用 Qt 信号槽机制实现模块间的松耦合通信 |

### 1.3 MVC 模式说明

Qt Widget 客户端采用经典的 **MVC (Model-View-Controller)** 架构模式：

```
┌─────────────────────────────────────────────────────────────────────┐
│                         用户交互流程                                 │
│                                                                      │
│   ┌─────────┐    用户操作    ┌─────────────┐    更新数据    ┌───────┐│
│   │  View   │ ────────────> │ Controller  │ ────────────> │ Model ││
│   │ (Widget)│               │             │               │(数据) ││
│   └─────────┘               └─────────────┘               └───────┘│
│        ▲                          │                            │    │
│        │                          │                            │    │
│        │        状态查询           │        数据变更通知         │    │
│        └──────────────────────────┴────────────────────────────┘    │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

**组件职责：**

| 组件 | 职责 | Qt 实现 |
|------|------|---------|
| **Model** | 数据管理、业务状态、数据持久化 | `QObject` 子类 + `QAbstractItemModel` |
| **View** | UI 渲染、用户交互、事件处理 | `QWidget` 子类 (QMainWindow, QDialog 等) |
| **Controller** | 业务逻辑、流程编排、协调 Model 和 View | `QObject` 子类，通过信号槽连接 |

**与 MVVM 的区别：**

| 方面 | MVVM (QML) | MVC (Widget) |
|------|------------|--------------|
| 数据绑定 | Property Binding (自动) | Signal/Slot (手动连接) |
| UI 定义 | .qml 声明式文件 | C++ 代码创建 Widget |
| 视图更新 | 绑定自动刷新 | 需要手动响应信号更新 |
| 状态管理 | ViewModel 集中管理 | Controller 协调 Model |

```cpp
// api/ApiClient.cpp
#include "ApiClient.h"
#include <QJsonDocument>
#include <QEventLoop>

namespace disk {
namespace api {

ApiClient::ApiClient(QObject* parent)
    : QObject(parent)
    , m_manager(new QNetworkAccessManager(this))
{
    connect(m_manager, &QNetworkAccessManager::finished,
            this, &ApiClient::onReplyFinished);
}

ApiClient::~ApiClient() {
    // 取消所有待处理请求
    for (auto it = m_pendingRequests.begin(); it != m_pendingRequests.end(); ++it) {
        it.key()->abort();
    }
    m_pendingRequests.clear();
}

void ApiClient::setBaseUrl(const QString& url) {
    m_baseUrl = url;
    if (!m_baseUrl.endsWith('/')) {
        m_baseUrl += '/';
    }
}

void ApiClient::setTokenProvider(std::function<QString()> provider) {
    m_tokenProvider = std::move(provider);
}

QNetworkRequest ApiClient::buildRequest(const QString& path) {
    QUrl url(m_baseUrl + path);
    QNetworkRequest request(url);
    
    request.setHeader(QNetworkRequest::ContentTypeHeader, "application/json");
    request.setRawHeader("Accept", "application/json");
    
    // 添加认证头
    if (m_tokenProvider) {
        QString token = m_tokenProvider();
        if (!token.isEmpty()) {
            request.setRawHeader("Authorization", 
                                QString("Bearer %1").arg(token).toUtf8());
        }
    }
    
    // 设置超时
    request.setTransferTimeout(m_timeout);
    
    return request;
}

QFuture<QByteArray> ApiClient::get(const QString& path, const QUrlQuery& query) {
    QSharedPointer<QPromise<QByteArray>> promise = 
        QSharedPointer<QPromise<QByteArray>>::create();
    promise->start();
    
    QString fullPath = path;
    if (!query.isEmpty()) {
        fullPath += "?" + query.toString();
    }
    
    QNetworkRequest request = buildRequest(fullPath);
    QNetworkReply* reply = m_manager->get(request);
    m_pendingRequests[reply] = promise;
    
    return promise->future();
}

QFuture<QByteArray> ApiClient::post(const QString& path, const QByteArray& body) {
    QSharedPointer<QPromise<QByteArray>> promise = 
        QSharedPointer<QPromise<QByteArray>>::create();
    promise->start();
    
    QNetworkRequest request = buildRequest(path);
    QNetworkReply* reply = m_manager->post(request, body);
    m_pendingRequests[reply] = promise;
    
    return promise->future();
}

void ApiClient::onReplyFinished(QNetworkReply* reply) {
    auto it = m_pendingRequests.find(reply);
    if (it == m_pendingRequests.end()) {
        reply->deleteLater();
        return;
    }
    
    auto promise = it.value();
    m_pendingRequests.erase(it);
    
    if (reply->error() == QNetworkReply::NoError) {
        promise->addResult(reply->readAll());
        promise->finish();
    } else {
        // 处理特定错误
        if (reply->error() == QNetworkReply::AuthenticationRequiredError) {
            emit tokenExpired();
        } else {
            emit networkError(reply->errorString());
        }
        promise->setException(std::make_exception_ptr(
            std::runtime_error(reply->errorString().toStdString())));
    }
    
    reply->deleteLater();
}

} // namespace api
} // namespace disk
```

#### 3.1.3 API 响应处理

```cpp
// api/ApiResponse.h
#pragma once

#include <QString>
#include <QJsonObject>
#include <QJsonDocument>
#include <optional>
#include <variant>
#include "utils/ErrorInfo.h"

namespace disk {
namespace api {

// API 响应结构
struct ApiResponse {
    int code{0};
    QString message;
    QJsonValue data;
    QJsonObject pagination;
    
    // 解析 JSON 响应
    static std::optional<ApiResponse> parse(const QByteArray& jsonData) {
        QJsonParseError error;
        QJsonDocument doc = QJsonDocument::fromJson(jsonData, &error);
        
        if (error.error != QJsonParseError::NoError) {
            return std::nullopt;
        }
        
        if (!doc.isObject()) {
            return std::nullopt;
        }
        
        QJsonObject obj = doc.object();
        ApiResponse response;
        response.code = obj["code"].toInt(0);
        response.message = obj["message"].toString();
        response.data = obj["data"];
        
        if (obj.contains("pagination")) {
            response.pagination = obj["pagination"].toObject();
        }
        
        return response;
    }
    
    // 检查是否成功
    bool isSuccess() const { return code == 0; }
    
    // 获取分页信息
    int page() const { return pagination["page"].toInt(1); }
    int pageSize() const { return pagination["page_size"].toInt(20); }
    int total() const { return pagination["total"].toInt(0); }
    int totalPages() const { return pagination["total_pages"].toInt(0); }
};

// 泛型结果类型
template<typename T>
using ApiResult = std::variant<T, ErrorInfo>;

// 结果辅助函数
template<typename T>
bool isSuccess(const ApiResult<T>& result) {
    return std::holds_alternative<T>(result);
}

template<typename T>
const T& getValue(const ApiResult<T>& result) {
    return std::get<T>(result);
}

template<typename T>
const ErrorInfo& getError(const ApiResult<T>& result) {
    return std::get<ErrorInfo>(result);
}

} // namespace api
} // namespace disk
```

```cpp
// services/AuthService.cpp
#include "AuthService.h"
#include <QJsonDocument>
#include <QJsonObject>

namespace disk {
namespace services {

AuthService::AuthService(api::ApiClient* client,
                        storage::TokenStore* tokenStore,
                        QObject* parent)
    : QObject(parent)
    , m_client(client)
    , m_tokenStore(tokenStore)
{
    // 设置 Token 提供者
    m_client->setTokenProvider([this]() {
        return m_tokenStore->accessToken();
    });
    
    // 监听 Token 过期信号
    connect(m_client, &api::ApiClient::tokenExpired, this, [this]() {
        // 自动尝试刷新 Token
        refreshToken().then([this](auto result) {
            if (!api::isSuccess(result)) {
                emit loggedOut();
            }
        });
    });
}

QFuture<api::ApiResult<LoginResult>> AuthService::login(const QString& username, 
                                                        const QString& password) {
    QJsonObject body;
    body["username"] = username;
    body["password"] = password;
    
    return m_client->post("/api/auth/login", 
                         QJsonDocument(body).toJson())
        .then([this](const QByteArray& data) -> api::ApiResult<LoginResult> {
            auto response = api::ApiResponse::parse(data);
            if (!response || !response->isSuccess()) {
                return ErrorInfo(response ? response->code : -1, 
                               response ? response->message : "解析响应失败");
            }
            
            LoginResult result;
            auto dataObj = response->data.toObject();
            result.accessToken = dataObj["access_token"].toString();
            result.refreshToken = dataObj["refresh_token"].toString();
            result.expiresAt = QDateTime::fromSecsSinceEpoch(
                dataObj["expires_at"].toInteger());
            
            auto userObj = dataObj["user"].toObject();
            result.user.id = userObj["id"].toInteger();
            result.user.username = userObj["username"].toString();
            result.user.storageUsed = userObj["storage_used"].toInteger();
            result.user.storageQuota = userObj["storage_quota"].toInteger();
            
            // 保存 Token
            saveTokens(result);
            m_currentUser = result.user;
            m_isAuthenticated = true;
            
            emit authenticated(result.user);
            return result;
        });
}

void AuthService::saveTokens(const LoginResult& result) {
    m_tokenStore->saveTokens(result.accessToken, 
                            result.refreshToken,
                            result.expiresAt);
}

bool AuthService::isAuthenticated() const {
    return m_isAuthenticated && hasValidToken();
}

bool AuthService::hasValidToken() const {
    return m_tokenStore->hasValidToken();
}

} // namespace services
} // namespace disk
```

```cpp
FileInfo::FileInfo(const QJsonObject& json) {
    id = json["id"].toVariant().toULongLong();

    size = json["size"].toVariant().toLongLong();
    parentId = json["parent_id"].toVariant().toULongLong();

QString FileInfo::displaySize() const {
    if (type == FileType::Folder) {
        return QString();
    }
    
    QLocale locale;
    const qint64 KB = 1024;
    const qint64 MB = KB * 1024;
    const qint64 GB = MB * 1024;
    
    if (size >= GB) {
        return locale.toString(size / (double)GB, 'f', 2) + " GB";
    } else if (size >= MB) {
        return locale.toString(size / (double)MB, 'f', 2) + " MB";
    } else if (size >= KB) {
        return locale.toString(size / (double)KB, 'f', 2) + " KB";
    }
    return locale.toString(size) + " B";
}

QString FileInfo::extension() const {
    if (isFolder()) {
        return QString();
    }
    int dotPos = name.lastIndexOf('.');
    if (dotPos > 0 && dotPos < name.length() - 1) {
        return name.mid(dotPos + 1).toLower();
    }
    return QString();
}
```

```cpp
// models/FileListModel.cpp
#include "FileListModel.h"

namespace disk {
namespace models {

FileListModel::FileListModel(QObject* parent)
    : QAbstractListModel(parent)
{
}

int FileListModel::rowCount(const QModelIndex& parent) const {
    if (parent.isValid()) {
        return 0;
    }
    return m_items.size();
}

QVariant FileListModel::data(const QModelIndex& index, int role) const {
    if (!index.isValid() || index.row() >= m_items.size()) {
        return QVariant();
    }
    
    const Item& item = m_items.at(index.row());
    
    switch (role) {
    case IdRole:
        return QVariant::fromValue(item.id());
    case NameRole:
        return item.name();
    case TypeRole:
        return item.isFolder ? "folder" : "file";
    case SizeRole:
        return item.isFolder ? 0 : item.file.size;
    case DisplaySizeRole:
        return item.displaySize();
    case MimeTypeRole:
        return item.isFolder ? QString() : item.file.mimeType;
    case ParentIdRole:
        return QVariant::fromValue(item.isFolder ? item.folder.parentId : item.file.parentId);
    case PathRole:
        return item.isFolder ? item.folder.path : item.file.path;
    case IconRole:
        return item.displayIcon();
    case ThumbnailRole:
        return item.isFolder ? QString() : item.file.thumbnailUrl;
    case CreatedAtRole:
        return item.isFolder ? item.folder.createdAt : item.file.createdAt;
    case UpdatedAtRole:
        return item.isFolder ? item.folder.updatedAt : item.file.updatedAt;
    case IsSharedRole:
        return item.isFolder ? false : item.file.isShared;
    case IsFolderRole:
        return item.isFolder;
    case ExtensionRole:
        return item.isFolder ? QString() : item.file.extension();
    case FileItemRole:
        return QVariant::fromValue(item.isFolder ? FileInfo() : item.file);
    default:
        return QVariant();
    }
}

QHash<int, QByteArray> FileListModel::roleNames() const {
    QHash<int, QByteArray> roles;
    roles[IdRole] = "fileId";
    roles[NameRole] = "fileName";
    roles[TypeRole] = "fileType";
    roles[SizeRole] = "fileSize";
    roles[DisplaySizeRole] = "displaySize";
    roles[MimeTypeRole] = "mimeType";
    roles[ParentIdRole] = "parentId";
    roles[PathRole] = "filePath";
    roles[IconRole] = "icon";
    roles[ThumbnailRole] = "thumbnail";
    roles[CreatedAtRole] = "createdAt";
    roles[UpdatedAtRole] = "updatedAt";
    roles[IsSharedRole] = "isShared";
    roles[IsFolderRole] = "isFolder";
    roles[ExtensionRole] = "extension";
    roles[FileItemRole] = "fileItem";
    return roles;
}

void FileListModel::setFiles(const QList<FileInfo>& files, const QList<FolderInfo>& folders) {
    beginResetModel();
    
    m_items.clear();
    
    // 先添加文件夹
    for (const FolderInfo& folder : folders) {
        Item item;
        item.isFolder = true;
        item.folder = folder;
        m_items.append(item);
    }
    
    // 再添加文件
    for (const FileInfo& file : files) {
        Item item;
        item.isFolder = false;
        item.file = file;
        m_items.append(item);
    }
    
    endResetModel();
    emit countChanged();
}

void FileListModel::clear() {
    if (m_items.isEmpty()) {
        return;
    }
    
    beginResetModel();
    m_items.clear();
    endResetModel();
    emit countChanged();
}

FileInfo FileListModel::get(int index) const {
    if (index < 0 || index >= m_items.size()) {
        return FileInfo();
    }
    
    const Item& item = m_items.at(index);
    return item.isFolder ? FileInfo() : item.file;
}

void FileListModel::updateFile(const FileInfo& file) {
    for (int i = 0; i < m_items.size(); ++i) {
        if (!m_items[i].isFolder && m_items[i].file.id == file.id) {
            m_items[i].file = file;
            QModelIndex idx = index(i);
            emit dataChanged(idx, idx);
            return;
        }
    }
}

void FileListModel::removeFile(quint64 fileId) {
    for (int i = 0; i < m_items.size(); ++i) {
        if (m_items[i].id() == fileId) {
            beginRemoveRows(QModelIndex(), i, i);
            m_items.removeAt(i);
            endRemoveRows();
            emit countChanged();
            return;
        }
    }
}

void FileListModel::sortByName(Qt::SortOrder order) {
    beginResetModel();
    std::sort(m_items.begin(), m_items.end(), [order](const Item& a, const Item& b) {
        // 文件夹始终在前
        if (a.isFolder != b.isFolder) {
            return a.isFolder;
        }
        if (order == Qt::AscendingOrder) {
            return a.name().toLower() < b.name().toLower();
        }
        return a.name().toLower() > b.name().toLower();
    });
    endResetModel();
}

}
```

```cpp
    connect(m_service, &services::FileService::fileRenamed,
            this, [this](quint64 fileId, const QString& newName) {
                m_model->updateFile(m_model->getById(fileId));
                emit fileOperationCompleted("rename");
            });
    
    connect(m_service, &services::FileService::fileMoved,
            this, [this](quint64 fileId, quint64 newFolderId) {
                m_model->removeFile(fileId);
                emit fileOperationCompleted("move");
            });
    
    connect(m_service, &services::FileService::fileDeleted,
            this, [this](quint64 fileId) {
                m_model->removeFile(fileId);
                emit fileOperationCompleted("delete");
            });
}

void FileController::refresh() {
    if (m_isSearching) {
        search(m_searchKeyword);
    } else {
        loadFiles(m_currentFolderId);
    }
}

void FileController::navigateToFolder(quint64 folderId, const QString& folderName) {
    if (folderId == m_currentFolderId) {
        return;
    }
    
    m_navigationStack.push(m_currentFolderId);
    m_currentFolderId = folderId;
    updatePath(folderName);
    
    m_isSearching = false;
    m_searchKeyword.clear();
    
    loadFiles(folderId);
    emit currentFolderChanged();
}

void FileController::navigateUp() {
    if (!canNavigateUp()) {
        return;
    }
    
    m_currentFolderId = m_navigationStack.pop();
    loadFiles(m_currentFolderId);
    
    // 更新路径
    int lastSlash = m_currentPath.lastIndexOf('/');
    if (lastSlash > 0) {
        m_currentPath = m_currentPath.left(lastSlash);
    } else {
        m_currentPath = "/";
    }
    
    emit currentPathChanged();
    emit currentFolderChanged();
}

void FileController::navigateToRoot() {
    m_navigationStack.clear();
    m_currentFolderId = 0;
    m_currentPath = "/";
    m_isSearching = false;
    m_searchKeyword.clear();
    
    loadFiles(0);
    
    emit currentPathChanged();
    emit currentFolderChanged();
}

bool FileController::canNavigateUp() const {
    return !m_navigationStack.isEmpty();
}

void FileController::loadFiles(quint64 folderId) {
    setLoading(true);
    setError(QString());
    
    auto future = m_service->getFileList(folderId);
    
    auto* watcher = new QFutureWatcher<api::ApiResult<services::FileListResult>>(this);
    connect(watcher, &QFutureWatcherBase::finished, this, [this, watcher]() {
        auto result = watcher->result();
        setLoading(false);
        
        if (api::isSuccess(result)) {
            const auto& data = api::getValue(result);
            m_model->setFiles(data.files, data.folders);
            emit filesLoaded();
        } else {
            setError(api::getError(result).message());
        }
        
        watcher->deleteLater();
    });
    
    watcher->setFuture(future);
}

void FileController::rename(quint64 fileId, const QString& newName) {
    auto future = m_service->renameFile(fileId, newName);
    
    auto* watcher = new QFutureWatcher<api::ApiResult<models::FileInfo>>(this);
    connect(watcher, &QFutureWatcherBase::finished, this, [this, fileId, watcher]() {
        auto result = watcher->result();
        
        if (api::isSuccess(result)) {
            m_model->updateFile(api::getValue(result));
            emit fileOperationCompleted("rename");
        } else {
            emit fileOperationFailed("rename", api::getError(result).message());
        }
        
        watcher->deleteLater();
    });
    
    watcher->setFuture(future);
}

void FileController::remove(quint64 fileId) {
    auto future = m_service->deleteFile(fileId);
    
    auto* watcher = new QFutureWatcher<api::ApiResult<bool>>(this);
    connect(watcher, &QFutureWatcherBase::finished, this, [this, fileId, watcher]() {
        auto result = watcher->result();
        
        if (api::isSuccess(result)) {
            m_model->removeFile(fileId);
            m_selectedIds.remove(fileId);
            emit fileOperationCompleted("delete");
            emit selectionChanged();

            emit fileOperationFailed("delete", api::getError(result).message());
        }
        
        watcher->deleteLater();
    });
    
    watcher->setFuture(future);
}

void FileController::search(const QString& keyword) {
    if (keyword.isEmpty()) {
        clearSearch();

    m_searchKeyword = keyword;
    m_isSearching = true;
```

```cpp
// storage/TokenStore.cpp
#include "TokenStore.h"
#include <QCryptographicHash>
#include <QMessageAuthenticationCode>
#include <QRandomGenerator>

namespace disk {
namespace storage {

TokenStore::TokenStore(QObject* parent)
    : QObject(parent)
    , m_settings("Disk", "DiskClient")
{
    // 生成或加载加密密钥
    m_encryptionKey = m_settings.value("security/key").toByteArray();
    if (m_encryptionKey.isEmpty()) {
        m_encryptionKey = QRandomGenerator::global()->generateBytes(32);
        m_settings.setValue("security/key", m_encryptionKey);
    }
    
    loadFromSettings();
    
    // 检查 Token 是否过期
    if (hasValidToken() && m_expiresAt <= QDateTime::currentDateTime()) {
        emit tokenExpired();
    }
}

TokenStore::~TokenStore() {
    saveToSettings();
}

bool TokenStore::saveTokens(const QString& accessToken, 
                            const QString& refreshToken,
                            const QDateTime& expiresAt) {
    m_accessToken = accessToken;
    m_refreshToken = refreshToken;
    m_expiresAt = expiresAt;
    
    saveToSettings();
    emit tokenChanged();
    
    return true;
}

bool TokenStore::hasValidToken() const {
    return !m_accessToken.isEmpty() && 
           m_expiresAt.isValid() && 
           m_expiresAt > QDateTime::currentDateTime();
}

bool TokenStore::isTokenExpiringSoon(int secondsThreshold) const {
    if (!m_expiresAt.isValid()) {
        return true;
    }
    
    QDateTime threshold = QDateTime::currentDateTime().addSecs(secondsThreshold);
    return m_expiresAt <= threshold;
}

void TokenStore::clear() {
    m_accessToken.clear();
    m_refreshToken.clear();
    m_expiresAt = QDateTime();
    
    m_settings.remove("tokens/access");
    m_settings.remove("tokens/refresh");
    m_settings.remove("tokens/expires");
    
    emit tokenChanged();
}

QByteArray TokenStore::encrypt(const QString& data) const {
    if (data.isEmpty()) {
        return QByteArray();
    }
    
    // 使用 XOR 简单混淆（生产环境应使用更安全的加密）
    QByteArray plain = data.toUtf8();
    QByteArray result;
    result.resize(plain.size());
    
    for (int i = 0; i < plain.size(); ++i) {
        result[i] = plain[i] ^ m_encryptionKey[i % m_encryptionKey.size()];
    }
    
    return result.toBase64();
}

QString TokenStore::decrypt(const QByteArray& data) const {
    if (data.isEmpty()) {
        return QString();
    }
    
    QByteArray encoded = QByteArray::fromBase64(data);
    QByteArray result;
    result.resize(encoded.size());
    
    for (int i = 0; i < encoded.size(); ++i) {
        result[i] = encoded[i] ^ m_encryptionKey[i % m_encryptionKey.size()];
    }
    
    return QString::fromUtf8(result);
}

void TokenStore::loadFromSettings() {
    QByteArray encryptedAccess = m_settings.value("tokens/access").toByteArray();
    QByteArray encryptedRefresh = m_settings.value("tokens/refresh").toByteArray();
    qint64 expiresTimestamp = m_settings.value("tokens/expires").toLongLong();
    
    m_accessToken = decrypt(encryptedAccess);
    m_refreshToken = decrypt(encryptedRefresh);
    
    if (expiresTimestamp > 0) {
        m_expiresAt = QDateTime::fromSecsSinceEpoch(expiresTimestamp);
    }
}

void TokenStore::saveToSettings() {
    m_settings.setValue("tokens/access", encrypt(m_accessToken));
    m_settings.setValue("tokens/refresh", encrypt(m_refreshToken));
    
    if (m_expiresAt.isValid()) {
        m_settings.setValue("tokens/expires", m_expiresAt.toSecsSinceEpoch());
    }
}
```

```cpp
// 哈希计算在后台线程执行

class HashCalculator : public QObject {
    Q_OBJECT

public:
    static QFuture<QString> calculateMd5(const QString& filePath) {
        return QtConcurrent::run([filePath]() -> QString {
            QCryptographicHash hash(QCryptographicHash::Md5);
            QFile file(filePath);
            
            if (!file.open(QIODevice::ReadOnly)) {
                return QString();
            }
            
            constexpr qint64 chunkSize = 8192;
            while (!file.atEnd()) {
                hash.addData(file.read(chunkSize));
                
                // 检查是否需要取消
                if (QThread::currentThread()->isInterruptionRequested()) {
                    return QString();
                }
            }
            
            return hash.result().toHex();
        });
    }
    
    static QFuture<QString> calculateSha256(const QString& filePath) {
        return QtConcurrent::run([filePath]() -> QString {
            QCryptographicHash hash(QCryptographicHash::Sha256);
            QFile file(filePath);
            
            if (!file.open(QIODevice::ReadOnly)) {
                return QString();
            }
            
            constexpr qint64 chunkSize = 8192;
            while (!file.atEnd()) {
                hash.addData(file.read(chunkSize));
            }
            
            return hash.result().toHex();
        });
    }
};

// 在上传服务中使用
void UploadService::initUpload(UploadTask* task, const QString& hash) {
    task->setStatus(UploadStatus::CalculatingHash);
    
    auto future = HashCalculator::calculateSha256(task->filePath());
    
    auto* watcher = new QFutureWatcher<QString>(this);
    connect(watcher, &QFutureWatcherBase::finished, this, [this, task, watcher]() {
        QString hash = watcher->result();
        if (hash.isEmpty()) {
            task->setErrorMessage(tr("计算文件哈希失败"));
            task->setStatus(UploadStatus::Failed);
            return;
        }
        
        // 继续上传流程
        startUpload(task, hash);
        watcher->deleteLater();
    });
    
    watcher->setFuture(future);
}
```

```cpp
        return 507;
    case ErrorCode::NetworkError:
    case ErrorCode::ConnectionTimeout:
    case ErrorCode::InternalError:
    default:
        return 500;
    }
}

QJsonObject ErrorInfo::toJson() const {
    QJsonObject obj;
    obj["code"] = static_cast<int>(m_code);
    obj["message"] = m_message;
    return obj;
}

ErrorInfo ErrorInfo::fromJson(const QJsonObject& json) {
    return ErrorInfo(
        json["code"].toInt(),
        json["message"].toString()
    );
}

ErrorInfo ErrorInfo::networkError(const QString& detail) {
    return ErrorInfo(ErrorCode::NetworkError, 
                    QString("网络错误: %1").arg(detail));
}

ErrorInfo ErrorInfo::fileError(ErrorCode code, const QString& filename) {
    QString msg;
    switch (code) {
    case ErrorCode::FileNotFound:
        msg = QString("文件不存在: %1").arg(filename);
        break;
    case ErrorCode::FileReadError:
        msg = QString("读取文件失败: %1").arg(filename);
        break;
    case ErrorCode::FileWriteError:
        msg = QString("写入文件失败: %1").arg(filename);
        break;
    default:
        msg = QString("文件操作错误: %1").arg(filename);
    }
    return ErrorInfo(code, msg);
}

ErrorInfo ErrorInfo::fromException(const std::exception& e) {
    return ErrorInfo(ErrorCode::InternalError, QString::fromStdString(e.what()));
}
```

```cpp
// 在 Controller 中处理错误

class FileController : public QObject {
    // ...
    
private slots:
    void onFileOperationFailed(const QString& operation, const QString& error) {
        // 记录错误
        qWarning() << "File operation failed:" << operation << "-" << error;
        
        // 显示错误通知
        setError(error);
        
        // 根据错误类型采取不同措施
        if (error.contains("token") || error.contains("认证")) {
            // 认证失败，需要重新登录
            emit authenticationRequired();
        } else if (error.contains("网络")) {
            // 网络错误，可以重试
            emit networkError(error);
        }
    }
};

class ErrorHandler : public QObject {
    Q_OBJECT

public:
    static ErrorHandler* instance();
    
    void handleError(const ErrorInfo& error, QWidget* parent = nullptr);
    void showWarning(const QString& message, QWidget* parent = nullptr);
    void showInfo(const QString& message, QWidget* parent = nullptr);
    bool confirm(const QString& message, QWidget* parent = nullptr);

signals:
    void errorOccurred(const ErrorInfo& error);
    void authenticationRequired();

private:
    ErrorHandler() = default;
};

// 使用示例
void FileController::remove(quint64 fileId) {
    if (!ErrorHandler::instance()->confirm(tr("确定要删除此文件吗？"))) {
        return;
    }
    
    auto future = m_service->deleteFile(fileId);
    
    auto* watcher = new QFutureWatcher<api::ApiResult<bool>>(this);
    connect(watcher, &QFutureWatcherBase::finished, this, [this, fileId, watcher]() {
        auto result = watcher->result();
        
        if (api::isSuccess(result)) {
            m_model->removeFile(fileId);
        } else {
            ErrorHandler::instance()->handleError(api::getError(result));
        }
        
        watcher->deleteLater();
    });
    
    watcher->setFuture(future);
}
```
