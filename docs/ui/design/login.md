# 登录页面设计

## 概述

登录页面是用户进入 Disk 网盘系统的入口，支持用户名或邮箱登录，提供记住密码功能。

---

## Qt Widget 设计

### 界面布局

使用 `QDialog` + `QVBoxLayout` 实现：

```
QDialog (居中显示)
└── QVBoxLayout
    ├── QWidget (Logo + 标题区域)
    │   └── QHBoxLayout
    │       ├── QLabel (Logo)
    │       └── QLabel (标题)
    ├── QFormLayout
    │   ├── QLineEdit (账号输入)
    │   └── QWidget (密码区域)
    │       └── QHBoxLayout
    │           ├── QLineEdit (密码输入, EchoMode=Password)
    │           └── QToolButton (显示/隐藏密码)
    ├── QCheckBox (记住密码)
    ├── QPushButton (登录按钮)
    ├── QWidget (弹性空间)
    └── QLabel (提示信息)
```

### 组件实现

| 组件 | 类型 | 说明 |
|------|------|------|
| m_accountEdit | QLineEdit | 账号输入框 |
| m_passwordEdit | QLineEdit | 密码输入框 (EchoMode=Password) |
| m_rememberCheck | QCheckBox | 记住密码复选框 |
| m_loginButton | QPushButton | 登录按钮 |
| m_toggleBtn | QToolButton | 密码显示/隐藏切换按钮 |
| m_statusLabel | QLabel | 状态/错误信息显示 |

### QStyleSheet 样式

```css
QDialog {
    background-color: #FFFFFF;
}

QLineEdit {
    border: 1px solid #E0E0E0;
    border-radius: 4px;
    padding: 8px 12px;
    min-height: 20px;
    font-size: 14px;
}

QLineEdit:focus {
    border-color: #2196F3;
}

QPushButton#loginButton {
    background-color: #2196F3;
    color: white;
    border: none;
    border-radius: 4px;
    padding: 10px 24px;
    font-size: 14px;
    font-weight: 500;
}

QPushButton#loginButton:hover {
    background-color: #1976D2;
}

QPushButton#loginButton:disabled {
    background-color: #BDBDBD;
}
```

### 交互实现

| 交互 | 实现方式 |
|------|----------|
| 居中显示 | `QDialog::move()` 计算屏幕中心位置 |
| 密码切换 | `QLineEdit::setEchoMode()` 切换 `Password` / `Normal` |
| 回车登录 | 连接 `QLineEdit::returnPressed` 信号到登录槽 |
| 加载动画 | `QMovie` + `QLabel` 或自定义 `QProgressIndicator` |

### 组件规格

| 组件 | 高度 | 说明 |
|------|------|------|
| 标题区 | 3 行 | Logo + 应用名称 |
| 输入框 | 1 行 | 带边框的输入区域 |
| 复选框 | 1 行 | 记住我选项 |
| 按钮 | 1 行 | 登录按钮 |
| 提示区 | 2 行 | 注册提示信息 |
| 总高度 | ~13 行 | 最小终端高度要求 |

### 颜色方案

| 元素 | 16色 | 256色 | 24位色 | 说明 |
|------|------|-------|--------|------|
| 标题 | Blue (4) | 33 | #268bd2 | 应用名称 |
| 输入框边框 | Default | - | - | 默认边框颜色 |
| 聚焦边框 | Blue (4) | 33 | #268bd2 | 当前输入焦点 |
| 错误边框 | Red (1) | 160 | #dc322f | 验证失败 |
| 按钮背景 | Blue (4) | 33 | #268bd2 | 登录按钮 |
| 按钮文字 | White (7) | 231 | #ffffff | 按钮文字 |
| 提示文字 | Gray | 244 | #808080 | 辅助提示 |

### 交互设计

| 按键 | 功能 |
|------|------|
| `Tab` | 切换输入焦点 |
| `Shift+Tab` | 反向切换焦点 |
| `Enter` | 提交登录 / 切换复选框 |
| `Space` | 切换复选框状态 |
| `Esc` | 退出程序 |

### 状态反馈

| 状态 | 显示 |
|------|------|
| 登录中 | 按钮显示 "登录中..." 并禁用 |
| 成功 | 跳转到主界面 |
| 失败 | 在按钮下方显示红色错误信息 |

## 通用设计规范

### 输入验证

| 字段 | 验证规则 |
|------|----------|
| 账号 | 非空，支持用户名或邮箱格式 |
| 密码 | 非空 |

### 错误提示

| 错误类型 | 提示信息 |
|----------|----------|
| 用户不存在 | 用户不存在 |
| 密码错误 | 用户名或密码错误 |
| 账户锁定 | 账户已锁定，请稍后重试 |
| 网络错误 | 网络连接失败，请检查网络 |
| 服务不可用 | 服务暂时不可用，请稍后重试 |

### 加载状态

- **按钮文字**：登录中...
- **按钮状态**：禁用
- **光标**：等待状态
- **动画**：显示加载指示器
