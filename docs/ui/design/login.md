# 登录页面设计 (v2.0)

## 概述

登录页面是用户进入 Disk 网盘系统的入口，支持用户名或邮箱登录。采用现代化的双区布局设计，左侧装饰区营造品牌氛围，右侧表单卡片承载核心交互。

**视觉风格**: 渐变背景 + 玻璃态卡片 + 流畅动效

## 左侧装饰区

### 视觉设计

```
背景: 线性渐变 (135deg)
  从: #06A7FF (Primary)
  到: #40BFFF (Primary Light)

装饰元素:
  • 大型模糊圆点 (backdrop-filter: blur)
  • 半透明几何图形
  • 细线网格 (可选)
```

### 内容展示

```
┌─────────────────────────────────┐
│                                 │
```

## 右侧表单区

### Logo 区域

```
        ┌────────────┐
        │    🌀      │
        │   Logo     │     64px
        └────────────┘
        
          Disk
        欢迎回来
      登录你的账号
```

- Logo: 64px
- 产品名: 20px / 600
- 欢迎文字: 14px / 400 / Text Secondary

### 登录/注册切换

```
┌────────────────────────────────┐
│   登录    │    注册            │
│   ────    │                    │  ← 选中下划线
│  选中态    │   未选中           │
└────────────────────────────────┘
```

- 高度: 40px
- 选中: Primary 文字 + 下划线
- 未选中: Text Secondary
- 切换动画: 下划线滑动 200ms

### 输入框设计

#### 账号输入框

```
账号（用户名/邮箱）
┌────────────────────────────────┐
│ 👤  username@example.com       │
└────────────────────────────────┘
```

- 高度: 52px
- 圆角: 12px
- 图标: 用户图标 20px，左侧 16px
- 聚焦: Primary 边框 + Shadow

#### 密码输入框

```
密码
┌────────────────────────────────┐
│ 🔒  ••••••••••••          [👁]  │
└────────────────────────────────┘
```

- 高度: 52px
- 圆角: 12px
- 图标: 锁图标 20px，左侧 16px
- 显示/隐藏按钮: 眼睛图标，右侧 16px

### 登录按钮

```
┌────────────────────────────────┐
│          登 录                │
└────────────────────────────────┘
```

- 高度: 52px
- 圆角: 12px
- 背景: Primary (#06A7FF)
- 文字: 白色 16px / 600
- 悬停: Primary Hover + Scale 1.02
- 按下: Scale 0.98

**加载状态**:
```
┌────────────────────────────────┐
│      ⏳ 登录中...             │
└────────────────────────────────┘
```

- 显示加载动画
- 按钮禁用

### 辅助链接

```
忘记密码？          立即注册 →
Text Secondary      Primary
```

- 悬停: 添加下划线
- 点击: 跳转到对应页面

### 第三方登录

```
 ─────── 其他方式登录 ───────

   [微信]   [QQ]   [企业微信]
   40px     40px     40px
   图标按钮  图标按钮  图标按钮
```

- 图标尺寸: 40px
- 图标圆角: 50%
- 悬停: 背景高亮 + Scale 1.05
- 间距: 24px

## 表单验证与反馈

### 验证规则

| 字段 | 验证规则 | 错误提示 |
|------|----------|----------|
| 账号 | 非空 | 请输入用户名或邮箱 |
| 密码 | 非空 | 请输入密码 |

### 错误提示

```
账号（用户名/邮箱）
┌────────────────────────────────┐
│ 👤  username                   │
└────────────────────────────────┘
❌ 用户不存在

密码
┌────────────────────────────────┐
│ 🔒  ••••••••••••          [👁]  │
└────────────────────────────────┘
❌ 用户名或密码错误
```

- 错误文字: Error 色
- 图标: 错误图标
- 输入框边框: Error 色

### 错误类型

| 错误类型 | 提示信息 |
|----------|----------|
| 用户不存在 | 用户不存在 |
| 密码错误 | 用户名或密码错误 |
| 账户锁定 | 账户已锁定，请 15 分钟后重试 |
| 网络错误 | 网络连接失败，请检查网络 |
| 服务不可用 | 服务暂时不可用，请稍后重试 |
