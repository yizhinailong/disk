# 分享管理页面设计

## 概述

分享管理页面用于创建、查看和管理文件分享链接，支持设置有效期和访问密码。

**导航路径**: 传输 > 分享

视觉样式：默认使用目标框架的默认样式与系统配色；本文档仅约束布局与交互，不约束具体配色、字体或深浅色切换。

## 通用设计规范

### 分享参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| file_ids | array | 是 | - | 文件/文件夹 ID 列表 |
| expire_days | integer | 否 | 7 | 有效天数：0/1/7/30 |
| password | string | 否 | - | 访问密码（4-8字符） |
| permission | string | 否 | download | 权限：view/download |

### 有效期选项

| 选项 | 天数 | 说明 |
|------|------|------|
| 1 天 | 1 | 短期分享 |
| 7 天 | 7 | 默认选项 |
| 30 天 | 30 | 长期分享 |
| 永久 | 0 | 永不过期 |

### 状态显示

| 状态 | 显示 |
|------|------|
| 有效 | 有效 (N天) |
| 即将过期 | 即将过期 (N天) |
| 已过期 | 已过期 |
| 永久 | 永久 |

### 密码指示

| 状态 | 显示 | 说明 |
|------|------|------|
| 有密码 | 🔒 | 密码保护 |
| 无密码 | - | 公开访问 |

## Qt/QML 实现状态

### 已实现功能 (Wave 3)

以下功能已在 `ui/diskqml/qml/views/SharePage.qml` (v0.1, 2026-03-05) 中实现:

- **分享列表**: 完整的列表视图，包含分页控制 (pageSize=100)
- **多选功能**: 支持单选/多选，选择状态管理
- **创建分享**: 创建对话框，支持文件ID输入、有效期选择、密码设置、权限配置
  - 有效期选项: 1天/7天/30天/永久 (默认7天)
  - 访问密码: 可选，4-8字符
  - 权限: 仅查看/可下载 (默认可下载)
- **取消分享**: 批量取消选中的分享，需二次确认
- **右键菜单**: 复制链接、取消分享
- **加载状态**: Loading指示器、错误提示、空状态处理
- **分页**: 上一页/下一页，显示总页数和总项数
- **状态显示**: 有效/已过期/已取消，颜色区分

**注**: 当前创建分享对话框使用文件ID手动输入方式 (临时方案)。未来应从文件列表直接选择文件进行分享。

### 未实现/延后功能

- 从文件列表选择文件进行分享 (当前需手动输入文件ID)
- 高级分享设置自定义UI (当前使用默认值)
