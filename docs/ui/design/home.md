# 首页设计 (v2.0)

## 概述

首页是 Disk 桌面客户端的默认起始页面，提供一站式文件概览和快捷操作入口。参考百度网盘首页设计，整合快捷操作、存储概览、分类统计和最近文件模块。

**视觉风格**: 卡片式布局 + 数据可视化 + 清爽蓝色主色调

## 模块设计

### 模块 1: 快捷操作区

**位置**: 页面顶部
**高度**: 64px

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   [⬆ 上传文件]      [📁 新建文件夹]                           [⚙ 个性化]   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 按钮设计

| 按钮 | 样式 | 功能 |
|------|------|------|
| 上传文件 | Primary 按钮，高度 40px | 打开文件选择器，可多选 |
| 新建文件夹 | Secondary 按钮，边框样式 | 弹出新建文件夹对话框 |
| 个性化 | 图标按钮 | 打开个性化设置（排序、显示选项）|

**上传按钮交互**:
- 点击: 打开系统文件选择器
- 拖拽文件到按钮: 直接开始上传
- 拖拽文件到窗口: 显示全屏上传遮罩

---

### 模块 2: 存储空间概览

**位置**: 左侧卡片
**尺寸**: 宽度 280px，高度自适应

```
┌────────────────────────┐
│                        │
│      存储空间概览       │
│                        │
│      ╭────────╮        │
│     ╱   25%   ╲       │  ← 环形进度图
│    │   ████    │       │
│     ╲________╱        │
│                        │
│    已用 2.5 GB         │
│    总共 10 GB          │
│                        │
│    [管理存储空间]      │  ← Secondary 按钮
│                        │
└────────────────────────┘
```

#### 环形图规格

- 尺寸: 120x120px
- 线宽: 12px
- 背景: Border (#DEE0E3)
- 已用: Primary (#06A7FF) 渐变
- 超过 80%: Warning 色
- 超过 95%: Error 色

#### 状态提示

| 使用比例 | 提示文字 | 颜色 |
|----------|----------|------|
| < 50% | 存储空间充足 | Primary |
| 50-80% | 已使用一半 | Primary |
| 80-95% | 存储空间不足 | Warning |
| >= 95% | 存储空间即将用完 | Error |

### 模块 5: 快速访问

**位置**: 最近使用下方
**高度**: 自适应

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   快速访问                                        [+ 添加快捷方式]          │
│   ────────────────────────────────────────────────────────────────────────  │
│                                                                             │
│   📁 工作              📁 个人              📁 项目              ...       │
│   📁 文档              📁 下载              📁 备份                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 快捷方式项

```
📁 工作文件夹名称
```

- 图标: 文件夹图标 20px
- 文字: 14px，最多显示 12 个字符
- 悬停: 显示删除按钮
- 点击: 跳转到对应文件夹

#### 添加快捷方式

- 点击按钮打开文件夹选择对话框
- 或从文件列表拖拽文件夹到该区域
- 最多显示 8 个快捷方式
