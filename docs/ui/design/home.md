# 首页设计

## 概述

首页是 Disk 桌面客户端的默认起始页面，为用户提供快速访问常用功能和概览信息的入口。首页包含三个核心模块：快捷操作、最近文件和存储空间。

视觉样式：默认使用目标框架的默认样式与系统配色；本文档仅约束布局与交互，不约束具体配色、字体或深浅色切换。

## 模块定义

### 模块 A: 最近文件

**功能**: 展示用户最近访问或修改的文件列表，方便快速定位常用文件。

**字段定义**:

| 字段 | 类型 | 说明 |
|------|------|------|
| icon | image | 文件类型图标 |
| name | string | 文件名 |
| modified | datetime | 最后修改时间 |

**交互行为**:

| 操作 | 行为 |
|------|------|
| 单击 | 选中文件项 |
| 双击文件 | 下载/预览文件 |
| 双击文件夹 | 进入该文件夹 |
| 右键 | 显示上下文菜单（打开、下载、重命名、删除等） |

**业务规则**:

- 最多显示 10 条记录
- 按修改时间倒序排列
- 同时包含文件和文件夹
- 点击文件夹直接进入该目录

### 模块 B: 存储空间

**功能**: 展示用户当前的存储配额使用情况。

**字段定义**:

| 字段 | 类型 | 说明 |
|------|------|------|
| used | string | 已使用空间（如 2.5 GB） |
| total | string | 总配额（如 10 GB） |
| percentage | number | 使用百分比（如 25） |

**交互行为**:

| 操作 | 行为 |
|------|------|
| 点击区域 | 跳转到设置页面（存储管理） |

**显示规则**:

- 进度条长度按百分比计算
- 使用量超过 80% 时显示警告色
- 使用量达到 100% 时显示错误色并禁止上传

### 模块 C: 快捷操作

**功能**: 提供常用操作的快速入口按钮。

**按钮定义**:

| 按钮 | 图标 | 功能 | 触发行为 |
|------|------|------|----------|
| 上传文件 | ⬆️ | 上传文件 | 打开文件选择对话框 |
| 新建文件夹 | 📁 | 创建文件夹 | 弹出新建文件夹对话框 |
| 上传队列 | ⬆️ | 查看上传任务 | 切换到传输模式-上传页面 |
| 下载队列 | ⬇️ | 查看下载任务 | 切换到传输模式-下载页面 |

**交互行为**:

- 按钮水平排列，间距均匀
- 悬停显示背景高亮
- 点击触发对应操作

## 空态/错误态

### 未登录状态

用户未登录时，首页显示登录引导：

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                                                             │
│                    请先登录以使用 Disk                        │
│                                                             │
│                    [ 登 录 ]                                 │
│                                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

点击登录按钮跳转到登录页面。

### 无最近文件

用户没有最近访问记录时：

```
┌─────────────────────────────────────────────────────────────┐
│ 最近文件                                                    │

│                                                             │
│                    上传您的第一个文件吧                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## Qt/QML 实现状态

### 已实现功能 (Wave 3)

以下功能已在 `ui/diskqml/qml/views/HomePage.qml` (v0.1, 2026-03-05) 中实现:

- **最近文件模块**:
  - 完整的文件列表视图 (最多10条，按 updated_at 降序排列)
  - 文件夹点击: 进入该文件夹 (通过 `FileListViewModel.navigateToFolder()`)
  - 文件点击: 触发下载 (通过 `TransfersViewModel.startDownload()`)
  - 显示字段: 图标、文件名、大小、修改时间
  - 加载状态: Loading指示器、错误提示、空状态处理
  - 刷新按钮: 手动刷新最近文件列表
  - 实现: `FileListViewModel.loadRecentFiles()` 方法 (通过 `FileService.GetRecentFiles()`)

- **快捷操作**: 上传文件、新建文件夹、上传队列、下载队列按钮
- **存储空间**: 进度显示、超额警告 (>80% 警告色, >=100% 错误色)

### 未实现/延后功能

- 用户资料页面跳转 (DEFERRED - 超出Wave 3范围)
- 存储管理设置页面 (DEFERRED - 超出Wave 3范围)
