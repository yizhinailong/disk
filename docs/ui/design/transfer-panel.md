# 传输页面设计

## 概述

传输页面用于显示和管理文件上传和下载任务,通过侧边栏导航访问。包含两个标签页:上传队列和下载队列,支持查看进度、暂停、继续和取消操作。

视觉样式:默认使用目标框架的默认样式与系统配色;本文档仅约束布局与交互,不约束具体配色、字体或深浅色切换。

### 操作按钮

| 按钮 | 功能 | 显示条件 |
|------|------|----------|
| ⏸ | 暂停任务 | 传输中 |

| 状态 | 说明 | 进度条颜色 |
|------|------|------------|

| 失败 | 传输失败 | Error 色 |
| 等待中 | 等待开始 | Border 色 |

## Qt/QML 设计

### TransferPage 组件

```cpp
class TransferPage : public QObject {
    Q_OBJECT
    Q_PROPERTY(int currentTab READ currentTab WRITE setCurrentTab NOTIFY currentTabChanged)
    Q_PROPERTY(QObject* uploadModel READ uploadModel CONSTANT)
    Q_PROPERTY(QObject* downloadModel READ downloadModel CONSTANT)
    
public:
    Q_INVOKABLE void pauseTask(const QString& taskId);
    Q_INVOKABLE void resumeTask(const QString& taskId);
    Q_INVOKABLE void cancelTask(const QString& taskId);
    Q_INVOKABLE void retryTask(const QString& taskId);
    Q_INVOKABLE void clearCompleted();
    Q_INVOKABLE void pauseAll();
    Q_INVOKABLE void resumeAll();
    
signals:
    void currentTabChanged();
};
```

## 通用设计规范

### 传输队列管理功能

| 功能 | 说明 |
|------|------|
| 查看传输队列 | 显示所有传输任务 |
| 暂停任务 | 暂停选中的任务 |
| 继续任务 | 继续暂停的任务 |
| 取消任务 | 取消选中的任务 |
| 清理已完成 | 清理已完成的任务 |
| 全部暂停 | 暂停所有任务 |
| 全部继续 | 继续所有暂停任务 |
| 重试失败 | 重试失败的任务 |

### 进度条规范

| 参数 | 值 |
|------|-----|
| 高度 | 4px (GUI) / 1行 (TUI) |
| 已完成颜色 | Primary 色 |
| 未完成颜色 | Border 色 |
| 圆角 | 2px (GUI) |
| TUI 长度 | 40-60 字符 |

### 文件大小格式化

| 大小范围 | 显示格式 | 示例 |
|----------|----------|------|
| < 1 KB | `xxx B` | `512 B` |
| < 1 MB | `xxx KB` | `1.5 KB` |
| < 1 GB | `xxx MB` | `2.3 MB` |
| >= 1 GB | `xxx GB` | `1.2 GB` |

### 速度显示

| 速度范围 | 显示格式 | 示例 |
|----------|----------|------|
| < 1 KB/s | `xxx B/s` | `512 B/s` |
| < 1 MB/s | `xxx KB/s` | `512 KB/s` |
| >= 1 MB/s | `xxx MB/s` | `2.1 MB/s` |

### 剩余时间计算

```
剩余时间 = (总大小 - 已传输) / 当前速度
```

**显示格式**:
- < 1 分钟: `约 xx 秒`
- < 1 小时: `约 xx 分钟`
- >= 1 小时: `约 xx 小时 xx 分钟`

### 业务规则

| 规则 | 说明 |
|------|------|
| 传输队列持久化 | 应用重启后恢复未完成任务 |
| 传输状态实时更新 | 进度、速度、剩余时间 |
| 任务优先级调整 | 支持拖拽调整优先级 |
| 失败任务重试 | 支持手动重试 |
| 并发控制 | 限制同时传输任务数量 |
| 断点续传 | 支持中断后继续传输 |
