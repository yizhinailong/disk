# 主窗口设计 (v2.0)

## 概述

主窗口是 Disk 桌面客户端的核心界面，采用现代化的左侧导航 + 顶部工具栏 + 主内容区布局，参考百度网盘的清爽简洁风格。

**视觉风格**: 扁平化 + 微渐变 + 卡片式设计，蓝色主色调 (#06A7FF)

---

## 标题栏设计

### 布局结构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ┌────┐                    ┌─────────────────────┐   ┌──────────────────┐   │
│ │ 🌀 │  Disk              │ 🔍 搜索文件...      │   │ 🔔  👤  ⚙  ━  ✕  │   │
│ └────┘  16px 产品名       │     280px 搜索框    │   │ 通知 头像 设置 窗口 │   │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 组件规格

| 组件 | 尺寸 | 说明 |
|------|------|------|
| Logo | 32x32px | 应用图标 |
| 产品名 | 16px / 600 | "Disk" 文字 |
| 搜索框 | 280x36px | 全局搜索，Placeholder "搜索文件、文件夹..." |
| 通知图标 | 20px | 未读消息红点提示 |
| 用户头像 | 32px | 圆形头像，点击展开菜单 |
| 设置按钮 | 20px | 快速设置入口 |
| 窗口控制 | 12px | 最小化/最大化/关闭 |

### 搜索框

```
┌─────────────────────────────────┐
│ 🔍 搜索文件、文件夹...    ⌘ K   │
└─────────────────────────────────┘
```

- 聚焦时展开至 360px
- 支持快捷键 ⌘/Ctrl + K 聚焦
- 搜索结果下拉浮层

## 导航栏设计

### 整体结构

```
┌─────────────────────┐
│                     │
│  🏠 首页            │  ← 首页入口
│                     │
│  📁 全部文件         │  ← 文件管理主入口
│                     │
│  📤 传输            │  ← 传输管理
│     ├─ 正在传输      │     2个  ← 子菜单（可选展开）
│     └─ 传输完成      │     128个
│                     │
│  🔗 我的分享         │  ← 分享管理
│                     │
│  🗑️ 回收站          │  ← 回收站
│                     │
├─────────────────────┤
│                     │
│  ⚙ 设置             │  ← 设置入口
│                     │
│  ◀                  │  ← 折叠按钮
│                     │
└─────────────────────┘
```

### 导航项规格

| 属性 | 值 |
|------|------|
| 高度 | 44px |
| 图标 | 20px |
| 文字 | 14px / 400 |
| 图标-文字间距 | 12px |
| 内边距 | 16px |
| 外边距 | 4px（左右）|
| 圆角 | 8px |

### 导航项状态

```
默认状态:                    悬停状态:                   选中状态:
┌─────────────────────┐    ┌─────────────────────┐    ┌─────────────────────┐
│ 📁 全部文件         │    │ 📁 全部文件         │    │ │📁 全部文件        │
└─────────────────────┘    └─────────────────────┘    └─────────────────────┘
Text Secondary             Hover 背景                  Primary 色 + Light 背景
                                                      左侧 3px Primary 指示条
```

```
│                     │
```

```
│        │
│   🔗   │
│        │

│   ⚙    │

└────────┘
```

- 宽度: 64px
- 图标居中
- 悬停显示 Tooltip
- 选中项有背景色指示

## 工具栏设计

### 首页工具栏

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  [⬆ 上传文件] [📁 新建文件夹]                                    [⚙ 个性化] │
│   PrimaryBtn    SecondaryBtn                                        IconBtn │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 文件页面工具栏

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  全部文件 > 工作 > 项目          │  [⊞] [☰]  │  排序 ▼  │  更多 ▼          │
│  ───────────────────────           ───────    下拉菜单    下拉菜单         │
│  面包屑导航（可点击）              视图切换                                 │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 面包屑导航

```
全部文件 > 工作 > 项目 > 文档 > 2026
   ↑        ↑      ↑
 可点击   可点击  当前目录（不可点击）
```

- 分隔符: ">" 或 "/"
- 可点击项: Text Secondary，悬变 Primary
- 当前项: Text Primary，不可点击

#### 视图切换

```
┌────────────────┐
│  ⊞  │  ☰      │  胶囊按钮组
│ 网格  列表     │
└────────────────┘
```

- 高度: 32px
- 圆角: Full (999px)
- 选中: Primary 背景 + 白色文字
- 未选中: 透明 + Text Secondary

#### 排序下拉

```
排序 ▼
├─ 名称 ↑
├─ 名称 ↓
├─ 大小 ↑
├─ 大小 ↓
├─ 修改时间 ↑
└─ 修改时间 ↓
```

### 批量操作工具栏（选中文件时）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  已选择 3 个项目              [下载] [分享] [移动到...] [复制到...] [删除]  │
└─────────────────────────────────────────────────────────────────────────────┘
```

- 背景: Primary Light (#E6F6FF)
- 左侧: 选中数量
- 右侧: 批量操作按钮
- 过渡动画: 滑入 200ms

## 状态栏设计

### 布局结构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  共 128 个项目  已选择 3 个              [████░░░░░░] 已用 2.5 GB / 10 GB   │
│  ─────────────  ───────────              ───────────────────────────────    │
│     统计              选中                      存储空间指示器               │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 存储空间指示器

```
[████████████████████░░░░░░░░░░░░░░░░░░░░]  已用 2.5 GB / 10 GB (25%)
 ```

- 容器宽度: 160px
- 高度: 6px
- 圆角: 3px
- 背景: Border (#DEE0E3)
- 已用: Primary (#06A7FF) 渐变
- 警告: >= 80% 变为 Warning 色
- 危险: >= 95% 变为 Error 色

### 状态栏交互

- 点击存储空间区域 → 打开设置-存储管理
- 显示上传/下载速度（传输时）
- 显示同步状态（未来扩展）

## 页面切换动画

### 导航切换

```
页面 A          过渡          页面 B
┌─────┐       ┌─────┐       ┌─────┐
│     │  →  →  │ 淡  │  →  →  │     │
│     │  150ms │ 出  │  150ms │     │
└─────┘       └─────┘       └─────┘
```

- 时长: 300ms
- 缓动: ease-in-out
- 效果: 淡入淡出 + 轻微位移
