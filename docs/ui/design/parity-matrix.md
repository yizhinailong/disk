# QML 桌面客户端功能清单

## 概述

本文档记录 Disk 桌面客户端（Qt/QML）的功能实现状态。文档基于现有设计文档整理，反映 AS-IS 状态。

**平台限制**:
- **Linux**: 系统托盘需要支持的桌面环境 (GNOME/KDE/XFCE)；开机自启动依赖 XDG autostart
- **Windows**: 完整支持托盘、自启动、通知；自启动需要应用在 PATH 中
