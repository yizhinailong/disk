# TUI↔QML 功能对等矩阵

## 概述

本文档记录 Disk 客户端 TUI（终端用户界面）与 QML（桌面客户端）的功能对等状态。文档基于现有设计文档整理，反映 AS-IS 状态，而非预期状态。

---

## 适用范围

**重要说明：** 登录/注册页面 intentionally 允许存在差异，不适用对等原则。

| 页面类型 | TUI | QML | 对等要求 |
|----------|-----|-----|----------|
| 登录页面 | ✓ 仅登录 | ✓ 登录 + 注册 | **不要求对等** |
| 主界面（登录后） | ✓ | ✓ | **要求对等** |

**对等原则适用范围：** 仅适用于登录后的主界面功能，包括文件管理、传输、分享、回收站、设置等核心业务功能。

## 平台特有功能汇总

### TUI 独有功能

| 类别 | 功能 | 说明 |
|------|------|------|
| 导航 | vim 风格快捷键 | j/k/gg/G/{n}G 导航 |
| 兼容性 | ASCII 降级模式 | 终端不支持 Unicode 时的备用显示 |
| 设置 | chunk_size | 分片上传大小配置 |
| 设置 | auto_refresh_token | 自动刷新令牌开关 |
| 对话框 | y/n 快捷确认 | 确认对话框支持 y/n 键 |

### QML 独有功能

| 类别 | 功能 | 说明 |
|------|------|------|
| 视图 | 网格视图 | 文件列表的网格显示模式 |
| 设置 | auto_start | 开机自启动 |
| 设置 | minimize_to_tray | 最小化到系统托盘 |
| 设置 | show_notifications | 显示系统通知 |
| 设置 | confirm_delete | 删除前确认对话框 |
| 交互 | 右键菜单 | 上下文菜单操作 |

## 登录页面差异说明

| 客户端 | 登录 | 注册 | 说明 |
|--------|------|------|------|
| TUI | ✓ | ✗ | 仅支持登录，注册需通过其他渠道 |
| QML | ✓ | ✓ | 支持完整的登录和注册流程 |

**设计决策：** 此差异为有意设计。TUI 面向已有账户的运维/开发人员，注册流程通常通过 Web 或桌面客户端完成。
