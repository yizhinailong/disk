# Disk 桌面客户端 - 功能需求规格

## 1. 文档说明

**视觉样式：使用 Qt Quick Controls 平台默认样式；不在文档中引入 AppTheme/Colors 等自定义样式模块。**


### 1.1 文档目的

本文档详细描述 Disk 网盘系统 Qt/QML 桌面客户端的功能需求规格，作为客户端设计和开发的依据。

### 1.2 需求优先级说明

| 优先级 | 标识 | 说明 |
|--------|------|------|
| 高 | P0 | 核心功能，必须实现 |
| 中 | P1 | 重要功能，应该实现 |
| 低 | P2 | 增强功能，可选实现 |

### 1.3 功能范围

**包含功能**：
- 认证模块（登录、注册、令牌刷新、登出）
- 文件浏览模块（列表/网格视图）
- 文件预览模块（图片、视频、PDF）
- 文件传输模块（上传、下载）
- 文件操作模块（重命名、移动、复制、删除）
- 文件夹管理模块
- 回收站模块
- 分享模块
- 文件搜索
- 系统模块（托盘、通知、设置）

**不包含功能**：
- 文件在线编辑（当前版本不支持在线编辑功能）

### 1.4 架构分层

**关键原则：C++ 层处理所有业务逻辑，QML 层仅负责 UI 展示。**

| 职责 | 实现层 | 说明 |
|------|--------|------|
| API 调用 | C++ | 所有网络请求由 C++ API 客户端处理 |
| 数据处理 | C++ | 文件哈希计算、数据验证、格式转换 |
| 业务逻辑 | C++ | Services、ViewModels、Models |
| 本地存储 | C++ | QSettings、文件缓存管理 |
| UI 渲染 | QML | 视图、组件、对话框 |
| 用户交互 | QML | 事件处理、输入委托 |

**禁止事项：**
- QML/JavaScript 中禁止包含业务逻辑
- QML 中禁止直接调用 REST API
- QML 中禁止执行数据处理（如哈希计算、加密）

## 2. 认证模块 [P0]

### 2.1 用户登录

#### 2.1.1 功能描述

用户通过用户名/邮箱和密码进行身份验证，获取访问令牌并进入主界面。

#### 2.1.2 输入参数

| 参数名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| account | string | 是 | 非空 | 用户名或邮箱 |
| password | string | 是 | 非空 | 密码 |
| remember | boolean | 否 | - | 记住密码 |

#### 2.1.3 业务规则

1. 支持用户名或邮箱登录
2. 登录成功后安全存储 `access_token` 和 `refresh_token`
3. Access Token 有效期 2 小时，Refresh Token 有效期 7 天
4. 登录成功后自动跳转到首页（侧边栏可导航至我的文件、回收站、上传、下载、分享等页面）
5. 「记住密码」功能安全存储登录凭证

#### 2.1.4 异常处理

| 错误场景 | 错误码 | 用户提示 |
|----------|--------|----------|
| 用户不存在 | 40100 | 用户不存在 |
| 密码错误 | 40101 | 用户名或密码错误 |
| 账户被锁定 | 40102 | 账户已锁定，请稍后重试 |
| 网络错误 | - | 网络连接失败，请检查网络 |
| 服务不可用 | - | 服务暂时不可用，请稍后重试 |

#### 2.1.5 UI 交互

- 登录窗口居中显示
- 支持密码显示/隐藏切换
- 支持回车键快捷登录
- 登录中显示加载动画

---

### 2.1.6 注册入口

登录页面提供「立即注册」入口，点击后切换至注册表单。注册表单设计详见 [注册页面设计](../design/register.md)。
---

### 2.2 令牌刷新

#### 2.2.1 功能描述

当 Access Token 过期时，使用 Refresh Token 自动获取新的 Access Token，实现无感刷新。

#### 2.2.2 触发条件

1. API 请求返回 `40108 TokenExpired` 错误
2. 客户端检测到 Access Token 即将过期（剩余时间 < 5 分钟）

#### 2.2.3 业务规则

1. 使用 Refresh Token 调用 `/api/auth/refresh` 获取新令牌
2. 刷新成功后更新本地存储的令牌
3. 刷新失败（Refresh Token 过期）则跳转到登录界面
4. 令牌刷新对用户透明，不中断当前操作

---

### 2.3 用户登出

#### 2.3.1 功能描述

用户主动登出，清除本地凭证并使服务端令牌失效。

#### 2.3.2 业务规则

1. 调用 `/api/auth/logout` 使服务端令牌失效
2. 清除本地存储的所有凭证
3. 清除用户缓存数据
4. 返回登录界面
5. 即使服务端登出失败，仍清除本地凭证

#### 3.1.2 视图模式

## 5. 文件传输模块 [P0]

### 5.1 文件上传

#### 5.1.1 功能描述

支持本地文件上传到网盘，包括分片上传、秒传和断点续传。

#### 5.1.2 上传流程

```
┌─────────────────────────────────────────────────────────────┐
│                      文件上传流程                            │
├─────────────────────────────────────────────────────────────┤
│  1. 选择文件                                                 │
│     用户通过文件选择器选择本地文件（支持多选）                  │
│                                                              │
│  2. 计算文件哈希                                             │
│     C++ 层计算文件 MD5 哈希值（后台线程）                      │
│                                                              │
│  3. 初始化上传                                               │
│     C++ 层调用 /api/file/upload/init，检测秒传/续传           │
│                                                              │
│  4. 分片上传（非秒传）                                        │
│     C++ 层将文件分割为 5MB 分片，逐个上传                      │
│                                                              │
│  5. 完成上传                                                 │
│     C++ 层调用完成接口，服务端合并分片                         │
└─────────────────────────────────────────────────────────────┘
```

#### 5.1.3 上传方式

| 方式 | 说明 |
|------|------|
| 工具栏按钮 | 点击「上传」按钮选择文件 |
| 拖拽上传 | 拖拽文件到窗口上传 |
| 右键菜单 | 右键空白区域选择「上传」 |
| 粘贴上传 | Ctrl+V 粘贴剪贴板图片/文件 |

#### 5.1.4 业务规则

1. **秒传检测**：初始化时服务端检测文件哈希，如已存在则直接完成
2. **断点续传**：检测未完成的上传任务，从断点处继续
3. **并发控制**：同时上传文件数限制（默认 3 个）
4. **存储空间检查**：上传前检查用户存储配额
5. **文件名冲突**：自动重命名（添加后缀）

---

### 5.2 文件下载

#### 5.2.1 功能描述

支持从网盘下载文件到本地，支持断点续传。

#### 5.2.2 下载方式

| 方式 | 说明 |

| 右键菜单 | 右键选择「下载」 |

4. **下载校验**：下载完成后验证文件大小和哈希

## 6. 文件操作模块 [P0]

### 6.1 重命名

#### 6.1.1 功能描述

重命名文件或文件夹。

#### 6.1.2 业务规则

1. 文件名不能包含特殊字符：`\ / : * ? " < > |`
2. 同一目录下不能有同名文件
3. 重命名后立即刷新列表

#### 6.1.3 UI 交互

- 选中文件后按 F2 或右键选择「重命名」
- 弹出对话框，预填充当前名称
- 支持回车确认、Esc 取消

---

### 6.2 移动

#### 6.2.1 功能描述

移动文件或文件夹到指定目录。

#### 6.2.2 业务规则

1. 支持批量移动（多选模式）
2. 不能移动到自身或子文件夹中
3. 目标文件夹中不能有同名文件

#### 6.2.3 UI 交互

- 选中文件后拖拽到目标文件夹
- 右键选择「移动到」，弹出文件夹选择器
- 文件夹选择器显示目录树

---

### 6.3 复制

#### 6.3.1 功能描述

复制文件或文件夹到指定目录。

#### 6.3.2 业务规则

1. 支持批量复制（多选模式）
2. 复制操作占用用户存储配额
3. 如有同名文件，自动添加后缀

---

### 6.4 删除（移入回收站）

#### 6.4.1 功能描述

将文件或文件夹移入回收站（软删除）。

#### 6.4.2 业务规则

1. 支持批量删除（多选模式）
2. 删除操作将文件移入回收站，不释放存储空间
3. 删除前需要确认（可配置）

---
