# Disk 桌面客户端 - 界面设计规范

## 1. 设计概述

**视觉样式：使用 Qt Quick Controls 平台默认样式。不使用任何自定义主题模块。**


### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **平台原生感** | 遵循各平台设计规范（Windows/macOS/Linux） |
| **简洁直观** | 信息层次清晰，操作路径简短 |
| **一致性** | 统一的视觉语言和交互模式 |
| **响应式** | 窗口大小自适应，支持高分屏 |
| **可访问性** | 支持键盘导航，高对比度模式 |

### 1.2 目标用户特征

| 用户类型 | 特征 | 设计考量 |
|----------|------|----------|
| **普通用户** | 偶尔使用，需要引导 | 提供直观的图标和提示 |
| **办公用户** | 频繁使用，追求效率 | 支持快捷键和批量操作 |
| **专业用户** | 大量文件管理 | 提供高级搜索和过滤功能 |

### 3.2 标题栏设计

**高度**: 40px

**内容**:
```
┌─────────────────────────────────────────────────────────────────────┐
│ [Logo] Disk                      [最小化] [最大化] [关闭]           │
└─────────────────────────────────────────────────────────────────────┘
```

**设计要点**:
- 无边框窗口，自定义标题栏
- 拖拽区域为整个标题栏
- Windows 风格：按钮在右侧
- macOS 风格：按钮在左侧（红黄绿）

### 3.3 侧边栏设计

**宽度**: 200px（可调整）

**内容结构**:
```
文件模式:
┌──────────────────┐
│ 首页             │
│                  │
│ 我的文件         │
│ 回收站           │
│                  │
│ 传输             │  (点击切换到传输模式)
└──────────────────┘

传输模式:
┌──────────────────┐
│ 首页             │
│                  │
│ 上传             │
│ 下载             │
│ 分享             │
│                  │
│ 文件             │  (点击切换到文件模式)
└──────────────────┘
```

**设计要点**:
- 导航项使用图标+文字
- 选中项高亮背景
- 悬停显示背景色
- 侧边栏支持两种模式切换：文件模式和传输模式
- 文件模式：首页、我的文件、回收站，底部切换按钮
- 传输模式：首页、上传、下载、分享，底部切换按钮

**已移除的导航项**:
- 全部文件 → 合并为我的文件
- 收藏夹 → 暂不实现
- 传输列表 → 改为传输模式下的上传/下载页面
- 我的分享 → 改为传输模式下的分享页面
- 快速访问 → 暂不实现

## 7. 响应式设计

### 7.1 断点定义

| 名称 | 宽度 | 说明 |
|------|------|------|
| Compact | < 800px | 侧边栏收起 |
| Medium | 800-1200px | 侧边栏展开 |
| Expanded | > 1200px | 侧边栏展开，三栏布局 |

### 7.2 适配策略

#### Compact 模式 (< 800px)

- 侧边栏自动收起，点击按钮展开
- 工具栏简化，部分按钮移至菜单
- 文件网格列数减少

#### Medium 模式 (800-1200px)

- 侧边栏展开
- 完整工具栏
- 标准网格布局

#### Expanded 模式 (> 1200px)

- 侧边栏可加宽
- 可选三栏布局（目录树 + 列表 + 详情）
- 更大的文件网格
