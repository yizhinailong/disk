# Disk TUI 客户端 - 功能需求规格

## 1. 文档说明

### 1.1 文档目的

本文档详细描述 Disk 网盘系统 TUI（Terminal User Interface）客户端的功能需求规格，作为客户端设计和开发的依据。

### 1.2 需求优先级说明

| 优先级 | 标识 | 说明 |
|--------|------|------|
| 高 | P0 | 核心功能，必须实现 |
| 中 | P1 | 重要功能，应该实现 |
| 低 | P2 | 增强功能，可选实现 |

### 1.3 功能范围

**包含功能**：
- 认证模块（登录、令牌刷新、登出）
- 文件浏览模块
- 文件传输模块（上传、下载）
- 文件操作模块（重命名、移动、复制、删除）
- 文件夹管理模块
- 回收站模块
- 分享模块
- 系统模块

**不包含功能**：
- 用户注册（TUI 客户端仅支持登录，注册需通过 Web 端完成）
- 分享访问/下载（本客户端仅支持创建和管理分享，不支持访问他人分享）

## 2. 认证模块 [P0]

### 2.1 用户登录

#### 2.1.1 功能描述

用户通过用户名/邮箱和密码进行身份验证，获取访问令牌并进入主界面。

#### 2.1.2 输入参数

| 参数名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| account | string | 是 | 非空 | 用户名或邮箱 |
| password | string | 是 | 非空 | 密码 |

#### 2.1.3 业务规则

1. 支持用户名或邮箱登录
2. 登录成功后存储 `access_token` 和 `refresh_token`
3. Access Token 有效期 2 小时，Refresh Token 有效期 7 天
4. 登录成功后自动跳转到文件列表界面
5. 支持「记住我」功能，本地安全存储登录凭证

#### 2.1.4 异常处理

| 错误场景 | 错误码 | 用户提示 |
|----------|--------|----------|
| 用户不存在 | 40100 | 用户不存在 |
| 密码错误 | 40101 | 用户名或密码错误 |
| 账户被锁定 | 40102 | 账户已锁定，请稍后重试 |
| 网络错误 | - | 网络连接失败，请检查网络 |
| 服务不可用 | - | 服务暂时不可用，请稍后重试 |

#### 2.1.5 UI 交互

```
┌─────────────────────────────────────────────┐
│              Disk TUI Client                │
│                                             │
│  账号: [________________________]           │
│  密码: [________________________]           │
│                                             │
│  [ ] 记住我                                 │
│                                             │
│           [ 登 录 ]                         │
│                                             │
│  提示: 新用户请在 Web 端注册                │
└─────────────────────────────────────────────┘
```

### 2.2 令牌刷新

#### 2.2.1 功能描述

当 Access Token 过期时，使用 Refresh Token 自动获取新的 Access Token，实现无感刷新。

#### 2.2.2 触发条件

1. API 请求返回 `40108 TokenExpired` 错误
2. 客户端检测到 Access Token 即将过期（剩余时间 < 5 分钟）

#### 2.2.3 业务规则

1. 使用 Refresh Token 调用 `/api/auth/refresh` 获取新令牌
2. 刷新成功后更新本地存储的令牌
3. 刷新失败（Refresh Token 过期）则跳转到登录界面
4. 令牌刷新对用户透明，不中断当前操作

#### 2.2.4 异常处理

| 错误场景 | 错误码 | 处理方式 |
|----------|--------|----------|
| Refresh Token 无效 | 40105 | 清除本地凭证，跳转登录界面 |
| Refresh Token 已过期 | 40108 | 清除本地凭证，跳转登录界面 |
| 网络错误 | - | 提示用户稍后重试，保留当前界面 |

---

### 2.3 用户登出

#### 2.3.1 功能描述

用户主动登出，清除本地凭证并使服务端令牌失效。

#### 2.3.2 业务规则

1. 调用 `/api/auth/logout` 使服务端令牌失效
2. 清除本地存储的所有凭证（access_token、refresh_token）
3. 清除用户缓存数据
4. 返回登录界面
5. 即使服务端登出失败，仍清除本地凭证（优雅降级）

#### 2.3.3 UI 交互

- 主菜单提供「退出登录」选项
- 退出前弹出确认对话框

## 3. 文件浏览模块 [P0]

### 3.1 文件列表

#### 3.1.1 功能描述

展示当前目录下的文件和文件夹列表，支持分页和排序。

#### 3.1.2 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| parent_id | integer | 否 | 0 | 父文件夹 ID，0 表示根目录 |
| page | integer | 否 | 1 | 页码 |
| page_size | integer | 否 | 50 | 每页数量 |
| sort_by | string | 否 | name | 排序字段：name/size/created_at/updated_at |
| sort_order | string | 否 | asc | 排序方向：asc/desc |
| type | string | 否 | all | 筛选类型：all/file/folder |

#### 3.1.3 列表字段

| 字段 | 类型 | 显示 | 说明 |
|------|------|------|------|
| id | integer | - | 文件/文件夹 ID |
| name | string | ✓ | 名称 |
| type | string | ✓ | 类型图标（📁/📄） |
| size | integer | ✓ | 文件大小（文件夹显示子项数量） |
| created_at | datetime | ✓ | 创建时间 |
| updated_at | datetime | ○ | 更新时间（可选显示） |

#### 3.1.4 业务规则

1. 文件和文件夹混合显示，通过图标区分
2. 文件夹显示子项数量，文件显示大小
3. 支持键盘快捷键翻页（PgUp/PgDn）
4. 列表支持单选和多选模式
5. 空目录显示友好提示

#### 3.1.5 异常处理

| 错误场景 | 错误码 | 处理方式 |
|----------|--------|----------|
| 文件夹不存在 | 50006 | 提示后跳转到根目录 |
| 令牌过期 | 40108 | 自动刷新令牌后重试 |
| 网络错误 | - | 显示错误提示，提供重试按钮 |

#### 3.1.6 UI 交互

```
┌───────────────────────────────────────────────────────────────┐
│ 📁 /文档/工作                                         [? 帮助] │
├───────────────────────────────────────────────────────────────┤
│   名称                    大小         创建时间       操作    │
├───────────────────────────────────────────────────────────────┤
│ 📁 项目文档               12 项        2026-01-10     >       │
│ 📁 会议记录               8 项         2026-01-08     >       │
│ 📄 年度报告.pdf           2.3 MB       2026-01-12     [空格]  │
│ 📄 工作计划.docx          156 KB       2026-01-11     [空格]  │
│ 📄 数据分析.xlsx          890 KB       2026-01-09     [空格]  │
├───────────────────────────────────────────────────────────────┤

```

### 3.2 文件夹导航

#### 3.2.1 功能描述

支持进入子文件夹、返回上级文件夹、跳转到指定文件夹。

#### 3.2.2 操作方式

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 进入文件夹 | Enter / → | 进入选中的文件夹 |
| 返回上级 | Backspace / ← / q | 返回上级文件夹 |
| 跳转根目录 | g | 直接跳转到根目录 |
| 刷新当前目录 | r / F5 | 刷新当前目录列表 |

#### 3.2.3 业务规则

1. 进入文件夹时更新文件列表
2. 返回上级时恢复之前的滚动位置
3. 支持文件夹导航历史记录
4. 根目录下返回上级无效

---

### 3.3 面包屑导航

#### 3.3.1 功能描述

显示当前目录的完整路径，支持点击跳转到任意上级目录。

#### 3.3.2 业务规则

1. 调用 `/api/folder/{folder_id}/breadcrumb` 获取路径信息
2. 路径显示格式：`/根目录/文档/工作`
3. 支持点击任意路径段跳转
4. 路径过长时自动省略中间部分

#### 3.3.3 UI 交互

```
 📁 /根目录 > 文档 > 工作
```

## 4. 文件传输模块 [P0]

### 4.1 文件上传

> **实现状态**: ⚠️ 部分实现（uploader 模块存在但 TUI 未集成，需通过命令行使用）

#### 4.1.1 功能描述

支持本地文件上传到网盘，包括分片上传、秒传和断点续传。

#### 4.1.2 上传流程

```
┌─────────────────────────────────────────────────────────────┐
│                      文件上传流程                            │
├─────────────────────────────────────────────────────────────┤
│  1. 选择文件                                                 │
│     用户通过文件选择器选择本地文件                            │
│                                                              │
│  2. 计算文件哈希                                             │
│     客户端计算文件 MD5 哈希值                                 │
│                                                              │
│  3. 初始化上传                                               │
│     调用 /api/file/upload/init，检测秒传/续传                 │
│                                                              │
│  4. 分片上传（非秒传）                                        │
│     将文件分割为 5MB 分片，逐个上传                           │
│                                                              │
│  5. 完成上传                                                 │
│     调用完成接口，服务端合并分片                              │
└─────────────────────────────────────────────────────────────┘
```

#### 4.1.3 输入参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file_path | string | 是 | 本地文件路径 |
| parent_id | integer | 否 | 目标文件夹 ID，默认当前目录 |

#### 4.1.4 业务规则

1. **秒传检测**：初始化时服务端检测文件哈希，如已存在则直接完成
2. **断点续传**：检测未完成的上传任务，从断点处继续
3. **分片大小**：默认 5MB，大文件自动调整
4. **并发控制**：同时上传文件数限制（默认 3 个）
5. **存储空间检查**：上传前检查用户存储配额

#### 4.1.5 异常处理

| 错误场景 | 错误码 | 处理方式 |
|----------|--------|----------|
| 存储空间不足 | 50004 | 提示用户清理空间或升级配额 |
| 文件名无效 | 50001 | 提示用户重命名文件 |
| 网络中断 | - | 自动暂停，网络恢复后继续 |
| 上传任务过期 | 50008 | 重新初始化上传任务 |
| 分片校验失败 | 50009 | 重传该分片 |

## 5. 文件操作模块 [P0]

### 5.1 重命名

#### 5.1.1 功能描述

重命名文件或文件夹。

#### 5.1.2 输入参数

| 参数名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| file_id | integer | 是 | - | 文件/文件夹 ID |
| new_name | string | 是 | 1-255字符，不含非法字符 | 新名称 |

#### 5.1.3 业务规则

1. 文件名不能包含特殊字符：`\ / : * ? " < > |`
2. 同一目录下不能有同名文件
3. 重命名后立即刷新列表

#### 5.1.4 异常处理

| 错误场景 | 错误码 | 处理方式 |
|----------|--------|----------|
| 文件不存在 | 50005 | 提示文件已被删除，刷新列表 |
| 文件名无效 | 50001 | 提示非法字符，重新输入 |
| 同名文件存在 | 50007 | 提示已存在同名文件 |

#### 5.1.5 UI 交互

- 选中文件后按 `F2` 或 `r` 进入重命名模式
- 弹出输入框，预填充当前名称
- `Enter` 确认，`Esc` 取消

#### 5.2.5 UI 交互

- 选中文件后按 `m` 进入移动模式

|--------|------|------|----------|------|

| parent_id | integer | 否 | 默认当前目录 | 父文件夹 ID |

#### 6.1.3 业务规则

1. 文件夹名不能包含特殊字符：`\ / : * ? " < > |`
2. 禁止 `.` 和 `..` 作为文件夹名
3. 同一目录下不能有同名文件夹
4. 创建成功后刷新目录列表

#### 6.1.4 异常处理

| 错误场景 | 错误码 | 处理方式 |
|----------|--------|----------|
| 文件夹名无效 | 50001 | 提示非法字符，重新输入 |
| 同名文件夹存在 | 50010 | 提示已存在同名文件夹 |
| 父文件夹不存在 | 50006 | 提示父文件夹无效 |

#### 6.1.5 UI 交互

- 按 `n` 或 `F7` 创建新文件夹
- 弹出输入框，默认名称「新建文件夹」
- `Enter` 确认，`Esc` 取消
