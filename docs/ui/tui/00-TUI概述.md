# Disk TUI 客户端 - 系统概述

## 1. 项目简介

> 视觉样式：使用终端默认前景/背景与 Bubbles 组件默认样式；不提供额外的视觉配置项。

### 1.1 项目背景

Disk 网盘系统已通过 Drogon 框架实现了高性能的后端服务，提供了完整的文件存储、分享和管理功能。然而，当前仅提供基于 Qt/QML 的桌面客户端和 RESTful API，缺乏适合终端用户使用的命令行界面工具。

本项目旨在为 Disk 网盘系统开发一个现代化、用户友好的 **Terminal User Interface (TUI)** 客户端，为喜欢命令行操作的用户提供高效的文件管理体验。

### 1.2 项目目标

- **用户友好**：提供直观的引导界面，降低普通用户的使用门槛
- **高效操作**：支持 vim 风格的快捷键，提升高级用户的操作效率
- **功能完整**：覆盖后端提供的核心功能（文件管理、分享、上传下载）
- **跨平台**：支持 Linux、macOS 和 Windows 终端
- **高性能**：响应迅速，资源占用低

### 1.3 适用范围

本客户端适用于：
- 习惯命令行操作的 Linux/macOS 用户
- 需要远程管理文件的运维人员
- 希望快速上传下载文件的技术用户
- 追求高效操作体验的高级用户

| 特性 | 说明 |

| 组件化设计 | 界面拆分为独立组件，每个组件管理自身状态 |

### 2.3 核心设计模式

#### 2.3.1 Bubble Tea 模式

```go
// Model: 应用状态
type Model struct {
    files     []File
    cursor    int
    selected  map[int]bool
}

// Update: 状态更新
func (m Model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
    switch msg := msg.(type) {
    case tea.KeyMsg:
        switch msg.String() {
        case "j":
            m.cursor++
        case "k":
            m.cursor--
        }
    }
    return m, nil
}

// View: 界面渲染
func (m Model) View() string {
    return "渲染界面..."
}
```

```go
// 主界面由多个子组件组合而成
type MainModel struct {
    filelist    filelist.Model
    breadcrumb  breadcrumb.Model
    statusbar   statusbar.Model
    infopanel   infopanel.Model
}
```

### 4.2 模块职责

#### 4.2.1 认证模块 (Auth Module)

- **用户登录**：通过用户名/邮箱和密码进行身份验证
- **Token 管理**：存储和自动刷新 JWT Token
- **加密存储**：Token 使用 AES 加密存储到本地文件
- **自动登录**：记住登录状态，下次启动自动认证

> **注意**：TUI 客户端不提供用户注册功能，用户需通过其他渠道注册账户。

#### 4.2.2 文件模块 (File Module)

- **文件列表**：展示当前目录下的文件和文件夹
- **文件详情**：查看文件大小、类型、修改时间等元信息
- **文件下载**：单文件下载，支持多线程和断点续传
- **文件操作**：重命名、移动、复制、删除文件
- **文件夹管理**：创建、删除、进入文件夹
- **回收站**：查看、恢复、彻底删除回收站内容

> **注意**：当前版本不包含文件搜索功能（后端未实现）。

#### 4.2.3 上传模块 (Upload Module)

- **分片上传**：大文件自动分片上传
- **断点续传**：中断后可从断点继续上传
- **秒传检测**：基于文件哈希的快速上传
- **进度显示**：实时显示上传进度和速度
- **批量上传**：支持多个文件同时上传

#### 4.2.4 分享模块 (Share Module)

- **创建分享**：创建文件或文件夹的分享链接
- **分享设置**：设置有效期和访问密码
- **分享列表**：查看已创建的分享
- **取消分享**：删除分享链接

#### 4.2.5 配置模块 (Config Module)

- **服务器配置**：设置 API 服务器地址和端口
- **认证配置**：管理 Token 存储路径和加密密钥
- **界面配置**：自定义快捷键和界面样式
- **日志配置**：设置日志级别和输出路径

## 7. 性能指标

### 7.1 目标指标

| 指标类型 | 指标项 | 目标值 |
|----------|--------|--------|
| 响应时间 | 界面渲染延迟 | < 16ms (60fps) |
| 响应时间 | 按键响应延迟 | < 50ms |
| 内存占用 | 空闲状态 | < 50 MB |
| 内存占用 | 大列表渲染（10000项） | < 200 MB |
| 启动时间 | 冷启动 | < 500ms |
| 启动时间 | 热启动（已登录） | < 200ms |
| 传输速度 | 上传速度 | 达到网络带宽上限 |
| 传输速度 | 下载速度 | 达到网络带宽上限 |

### 7.2 优化策略

#### 7.2.1 渲染优化

1. **虚拟列表**：大列表只渲染可见区域，减少 DOM 操作
2. **增量更新**：仅更新变化的部分界面，避免全量重绘
3. **防抖处理**：快速输入时合并更新请求

#### 7.2.2 内存优化

1. **流式处理**：大文件上传下载使用流式读写，避免内存溢出
2. **缓存策略**：合理设置文件列表缓存，减少 API 请求
3. **资源释放**：及时释放不再使用的资源

#### 7.2.3 网络优化

1. **连接复用**：HTTP Keep-Alive 连接复用
2. **并发控制**：合理控制并发上传下载数量
3. **断点续传**：支持大文件断点续传，避免重复传输
