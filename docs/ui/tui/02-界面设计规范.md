# Disk TUI - 界面设计规范

## 1. 设计概述

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **效率优先** | 键盘操作为主，减少鼠标依赖，支持 vim 风格快捷键 |
| **信息清晰** | 层次分明的信息展示，重要信息突出显示 |
| **操作直观** | 常用操作一键触达，提供即时反馈 |
| **兼容性强** | 兼容主流终端（xterm、gnome-terminal、iTerm2、Windows Terminal） |
| **渐进学习** | 新手可通过提示操作，高级用户可使用快捷键 |

### 1.2 目标用户特征

| 用户类型 | 特征 | 设计考量 |
|----------|------|----------|
| **开发者** | 熟悉 vim/终端操作，追求效率 | 提供完整的 vim 风格快捷键 |
| **系统管理员** | 需要远程服务器文件管理 | 支持低带宽环境，最小终端尺寸 |
| **普通用户** | 偶尔使用终端，需要引导 | 底部显示快捷键提示，提供帮助页面 |

```
│                          2. 面包屑导航区 (1行)                           │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│                                                                         │
│                         3. 主内容区 (自适应)                             │
│                         文件/文件夹列表                                   │
│                                                                         │
│                                                                         │
├─────────────────────────────────────────────────────────────────────────┤
│                         4. 传输状态栏 (0-N行)                            │
├─────────────────────────────────────────────────────────────────────────┤
│                          5. 底部操作栏 (1行)                             │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2.3 顶部状态栏

**高度**: 1 行

**内容结构**:
```
┌─────────────────────────────────────────────────────────────────────────┐
│ <应用名称> │ <用户信息> │ <存储空间> │ <日期时间>                      │
└─────────────────────────────────────────────────────────────────────────┘
```

**字段说明**:

| 字段 | 格式 | 示例 |
|------|------|------|
| 应用名称 | `Disk TUI v{version}` | `Disk TUI v1.0` |
| 用户信息 | `用户: {username}` | `用户: john_doe` |
| 存储空间 | `{已用}/{总量} ({百分比}%)` | `2.5GB/10GB (25%)` |
| 日期时间 | `YYYY-MM-DD HH:MM` | `2026-02-16 14:30` |

**样式**:
- 背景: 主色调（蓝色）
- 前景: 白色
- 分隔符: `│`

### 2.4 面包屑导航区

**高度**: 1 行

**内容结构**:
```
┌─────────────────────────────────────────────────────────────────────────┐
│  路径: 根目录 > 文件夹1 > 文件夹2 > ...                                  │
└─────────────────────────────────────────────────────────────────────────┘
```

**交互**:
- 点击路径项可跳转到对应目录
- 当前目录高亮显示
- 路径过长时从左侧截断显示 `... > 最后两级`

**样式**:
- 背景: 默认背景色
- 前景: 默认文字颜色
- 分隔符: `>` （灰色）
- 当前目录: 高亮颜色

### 2.5 主内容区（文件列表）

**高度**: 自适应（终端高度 - 4 ~ 5 行）

**列表项格式**:
```
<图标> <名称> ..................................... <大小>
```

**列布局**:

| 列 | 宽度 | 对齐 | 说明 |
|----|------|------|------|
| 图标 | 2字符 | 左对齐 | 文件类型图标 |
| 名称 | 自适应 | 左对齐 | 文件/文件夹名称 |
| 点填充 | 自适应 | - | 用 `.` 填充空白 |
| 大小 | 10字符 | 右对齐 | 文件大小（带单位） |

**选中状态**:
- 背景: 选中高亮色
- 前景: 白色
- 左侧添加 `▶` 指示器

**示例**:
```
  📁 2024项目
▶ 📄 年度报告.docx ..................................... 1.2 MB   ← 选中项
  📷 团队合影.jpg ..................................... 2.3 MB
```

### 2.6 传输状态栏

**高度**: 0 ~ N 行（无传输时隐藏）

**显示条件**:
- 有文件正在上传/下载时显示
- 多个传输任务时分行显示
- 最多显示 3 个任务，超出显示 `+N 个任务...`

**单个任务格式**:
```
<类型>: <文件名> <进度条> <百分比> │ <速度>
```

**进度条样式**:
- 已完成: `████████████████`
- 进行中: `░░░░░░░░░░`
- 总长度: 20 字符

**示例**:
```
上传: 文档.pdf ████████████████████░░░░░░░░ 67% │ 速度: 2.1 MB/s
下载: 项目.zip ████░░░░░░░░░░░░░░░░░░░░ 12% │ 速度: 1.8 MB/s
```

### 2.7 底部操作栏

**高度**: 1 行

**内容**: 快捷键提示

**格式**: `[<按键>]<功能> [<按键>]<功能> ...`

**默认显示**:
```
[u]上传 [d]下载 [r]重命名 [m]移动 [c]复制 [x]删除 [n]新建 [?]帮助
```

**上下文感知**:
- 回收站页面: `[r]恢复 [x]彻底删除 [E]清空 [?]帮助`
- 帮助页面: `[q]返回`

## 3. 快捷键映射表

### 3.1 全局快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|

### 5.5 降级策略

终端颜色支持降级方案：

```
24位色 (True Color)
    ↓ 不支持
256色 (8-bit)
    ↓ 不支持
16色 (ANSI)
    ↓ 不支持
无颜色 (单色)
```

**检测顺序**:
1. 检查 `$COLORTERM` 环境变量（`truecolor` 或 `24bit`）
2. 检查 `$TERM` 环境变量（`xterm-256color` 等）
3. 检查终端能力（`ncurses` 的 `has_colors()`）

**适配策略**:

- 文件列表支持多列显示
- 可选显示详细列（大小、修改时间、类型）

### 7.3 窗口大小变化处理

**事件处理**:
1. 监听 `SIGWINCH` 信号
2. 获取新的终端尺寸
3. 计算新的布局参数
4. 重绘界面

**边界处理**:

| 场景 | 处理方式 |
|------|----------|
| 宽度 < 80 | 显示警告提示，建议扩大窗口 |
| 高度 < 24 | 显示警告提示，建议扩大窗口 |
| 宽度 >= 80 | 正常显示，自动适配 |

**最小尺寸警告**:
```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ⚠️ 终端窗口过小                                                │
│                                                                 │
│   当前: 60 x 20                                                 │
│   最小要求: 80 x 24                                             │
│   推荐: 120 x 30                                                │
│                                                                 │
│   请调整终端窗口大小后继续...                                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 7.4 分页策略

当文件数量超过可显示行数时：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `page_size` | 自动计算 | 终端高度 - 固定行数 |
| `visible_items` | `page_size` | 当前页显示项数 |
| `scroll_threshold` | 3 | 距边缘 N 行时触发滚动 |

**滚动行为**:
- 选中到列表底部时，自动向下滚动一页
- 选中到列表顶部时，自动向上滚动一页
- 支持 `Ctrl+D` / `Ctrl+U` 半页滚动
- 支持 `Ctrl+F` / `Ctrl+B` 整页滚动
