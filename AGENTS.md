## Code Conventions

### 1. Trailing Return Types (Mandatory)

```cpp
// ALL non-template functions use trailing return types
auto Register(RegisterRequest request) -> drogon::Task<Result<RegisterResponse>>;
auto Hash(const std::string& password) -> Result<std::string>;
static constexpr auto GetAccessTokenExpireSeconds() noexcept -> int { return 7200; }
```

### 2. [[nodiscard]] (Mandatory)

Applied to all methods with meaningful return values:

```cpp
[[nodiscard]]
auto Register(RegisterRequest request) -> drogon::Task<Result<RegisterResponse>>;

[[nodiscard]]
static auto FromRequest(const drogon::HttpRequestPtr& req) -> Result<RegisterRequest>;
```

### 3. noexcept (Getters & Constexpr)

```cpp
[[nodiscard]]
auto HttpStatus() const noexcept -> drogon::HttpStatusCode;

[[nodiscard]]
static constexpr auto GetAccessTokenExpireSeconds() noexcept -> int { return 7200; }
```

### 4. Result<T> Pattern (std::expected)

```cpp
template <typename T>
using Result = std::expected<T, ErrorInfo>;

// Error return
co_return std::unexpected(ErrorInfo(ErrorCode::UsernameExists));

// Error propagation
if (!hash_result) {
    co_return std::unexpected(hash_result.error());
}

// Value extraction
const auto& user = user_opt.value();
```

### 5. Naming Conventions

| Category | Pattern | Examples |
|----------|---------|----------|
| **Classes/Structs** | `PascalCase` | `AuthController`, `RegisterResponse` |
| **Functions/Methods** | `PascalCase` | `Register()`, `FromRequest()` |
| **Private Members** | `m_snake_case` | `m_auth_service`, `m_db_client` |
| **Local Variables** | `snake_case` | `user`, `access_token` |
| **Constants** | `UPPER_SNAKE_CASE` | `DEFAULT_STORAGE_QUOTA` |
| **Namespaces** | `lowercase::nested` | `disk::auth`, `disk::utils` |

## Error Handling

### Error Code Ranges

```cpp
// 0: Success
// 10xxx: General errors (InvalidParameter, ValidationFailed, etc.)
// 40xxx: Auth errors (UsernameExists, InvalidCredentials, etc.)
// 50xxx: File errors (InvalidFilename, FileNotFound, etc.)
// 60xxx: Share errors (ShareNotFound, ShareExpired, etc.)
```

### Exception Handling (External Libraries Only)

Only catch exceptions from **external libraries** (Drogon, JWT), convert to Result<T>:

```cpp
try {
    CoroMapper<Users> mapper(m_db_client);
    user = co_await mapper.insert(user);
} catch (const drogon::orm::DrogonDbException& e) {
    LOG_ERROR << "数据库插入失败: " << e.base().what();
    co_return std::unexpected(ErrorInfo(ErrorCode::InternalError));
}
```

## DTO Pattern

```cpp
// Request DTO with validation
struct RegisterRequest {
    std::string username;
    std::string email;
    std::string password;
    
    [[nodiscard]]
    static auto FromRequest(const drogon::HttpRequestPtr& req) -> Result<RegisterRequest>;
    
private:
    [[nodiscard]]
    auto ValidateUsername() const -> bool;
};

// Response DTO
struct RegisterResponse {
    uint64_t id;
    std::string username;
    std::string email;
    
    [[nodiscard]]
    auto ToJson() const -> Json::Value;
};
```

## Testing (GTest)

### Naming Convention

```cpp
// ✅ CamelCase, NO underscores
TEST(PasswdHash, HashValidPassword) { }
TEST(RegisterRequest, UsernameTooShort) { }

// ❌ Wrong
TEST(PasswdHash, Hash_ValidPassword) { }
```

### ASSERT vs EXPECT

```cpp
// ASSERT_* - prerequisites (test cannot continue)
ASSERT_TRUE(result.has_value()) << "Should succeed";

// EXPECT_* - general assertions
EXPECT_FALSE(result->empty());
EXPECT_EQ(result->username, "test_user");
```

## Development Workflow

1. **Modify DB schema**: Edit `sql/init.sql`
2. **Regenerate models**: `drogon_ctl create model all`
3. **Create DTO**: Add to `src/dtos/{Module}Dto.hpp`
4. **Implement service**: Add to `src/services/`
5. **Add controller**: Add to `src/controllers/`
6. **Write tests**: Mirror structure in `test/`
