# 组件规范

## 1. 组件设计原则

### 1.1 设计哲学

- **单一职责**：每个组件只负责一个明确的 UI 功能，不耦合业务逻辑。
- **Props 向下传递**：数据通过 Props 从父组件流向子组件，避免隐式依赖。
- **Events 向上通知**：子组件通过事件通知父组件用户交互或状态变更。
- **Slots 扩展内容**：使用插槽允许父组件自定义组件内部特定区域的内容。
- **样式隔离**：组件样式使用 scoped CSS，全局主题通过 CSS Variables 统一管理。

### 1.2 与 Element Plus 的关系

本项目以 Element Plus 作为基础组件库，在其之上封装业务组件：

- **直接使用**：按钮、输入框、表单、表格、对话框等基础交互组件直接使用 Element Plus。
- **业务封装**：网盘特有的交互模式（如文件列表、面包屑导航、文件夹树）封装为业务组件。
- **主题覆盖**：通过 CSS Variables 覆盖 Element Plus 默认主题色，保持视觉一致性。

### 1.3 组件分类

| 分类 | 说明 | 存放路径 |
|------|------|----------|
| 通用组件 (Base) | 跨页面复用的纯展示/交互组件 | `src/components/base/` |
| 页面组件 (Page) | 特定页面场景的业务组件 | `src/components/page/` |
| 布局组件 (Layout) | 页面级布局骨架 | `src/components/layout/` |

### 2.2 间距规范

| Token | 值 | 使用场景 |
|-------|-----|----------|
| `--spacing-page` | 16px | 页面外边框距 |
| `--spacing-panel` | 12px | 卡片/面板间距 |
| `--spacing-compact` | 8px | 紧凑元素间距 |
| `--spacing-inset` | 12px | 面板内边距 |
| `--spacing-content` | 14px | 内容区域内边距 |

### 2.3 字体规范

| Token | 值 | 使用场景 |
|-------|-----|----------|
| `--font-family-base` | system-ui, -apple-system, sans-serif | 全局字体 |
| `--font-size-xs` | 12px | 辅助文字、标签 |
| `--font-size-sm` | 13px | 表格内容、次要信息 |
| `--font-size-base` | 14px | 正文、按钮、输入框 |
| `--font-size-lg` | 16px | 标题、空状态提示 |
| `--font-size-xl` | 18px | 页面主标题 |

### 2.4 圆角规范

| Token | 值 | 使用场景 |
|-------|-----|----------|
| `--radius-panel` | 10px | 外层卡片/面板 |
| `--radius-inner` | 8px | 内部容器、表格行 |
| `--radius-button` | 4px | 按钮、输入框、标签 |

### 2.5 断点规范

本项目仅面向桌面浏览器，最小分辨率 1366x768。

| 断点 | 宽度 | 说明 |
|------|------|------|
| `sm` | >= 1366px | 最小支持分辨率 |
| `md` | >= 1440px | 标准桌面 |
| `lg` | >= 1920px | 大屏桌面 |

## 3. 通用组件清单 (Base Components)

### PageState

**位置**: `src/components/base/PageState.vue`

**说明**: 页面状态包装器，统一管理 loading、empty、error、content、batchResult 五种状态。

**Props**:

| 名称 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `state` | `'loading' \| 'empty' \| 'error' \| 'content' \| 'batchResult'` | 是 | — | 当前页面状态 |
| `keepContent` | `boolean` | 否 | `false` | loading 时是否保留内容并显示遮罩 |
| `emptyText` | `string` | 否 | `'未找到项目'` | 空状态提示文字 |
| `emptyIcon` | `string` | 否 | `'empty'` | 空状态图标名 |
| `errorText` | `string` | 否 | `'发生错误'` | 错误状态提示文字 |
| `errorIcon` | `string` | 否 | `'error'` | 错误状态图标名 |

**Events**:

| 名称 | 参数 | 说明 |
|------|------|------|
| `retry` | — | 用户点击重试按钮 |
| `action` | — | 用户点击空状态操作按钮 |

**Slots**:

| 名称 | 说明 |
|------|------|
| `default` | 正常内容区域（content 状态时显示） |
| `batchResult` | 批量操作结果自定义展示 |

**使用示例**:

```vue
<PageState :state="pageState" :keep-content="true" @retry="fetchData">
  <FileList :files="fileList" />
  <template #batchResult>
    <BatchResult :result="batchResult" />
  </template>
</PageState>
```

## 5. 组件命名规范

### 5.1 文件命名

- 组件文件名使用 PascalCase，如 `FileList.vue`、`ShareDialog.vue`。
- 目录名使用 kebab-case，如 `src/components/base/`、`src/components/page/`。
- 单文件组件（SFC）统一使用 `.vue` 后缀。

### 5.2 组件名注册

- 全局注册的组件名与文件名保持一致，如 `FileList`。
- 局部导入的组件使用原名，不做额外重命名。

### 5.3 Props 命名

- Props 名使用 camelCase，如 `currentFolderId`、`selectedIds`。
- 布尔类型 Props 使用肯定语义命名，如 `loading`、`visible`，避免 `isLoading`、`isVisible`。
- 事件名使用 camelCase，如 `@navigateUp`、`@toggleFolderNavigator`。

### 5.4 事件命名

- 自定义事件使用动词或动词短语，如 `confirm`、`cancel`、`submit`。
- v-model 兼容事件使用 `update:modelValue` 或 `update:xxx` 格式。

### 5.5 Slot 命名

- 默认插槽不命名，使用 `<slot />`。
- 具名插槽使用 camelCase，如 `<slot name="batchResult" />`。

### 5.6 类型定义

- 组件相关的 TypeScript 接口定义放在 `src/types/components.ts` 中。
- 接口名使用 PascalCase，如 `DriveItem`、`UploadTask`、`ContextMenuItem`。
