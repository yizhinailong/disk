# Vue Web 客户端 — 需求规格与功能映射

## 1. 项目概述

本文档将桌面客户端（QML/C++）的功能清单映射到 Vue Web 客户端，为后续 API 接口设计、页面布局设计和代码实现提供需求基线。

Web 客户端采用 Vue 3 + Vite + TypeScript + Element Plus + Pinia + Axios 技术栈，目标平台为桌面浏览器，最小分辨率 1366x768。Web 客户端与桌面客户端共享同一套后端 RESTful API，不发明新的后端接口。

### 1.1 产品流定义

| 产品流 | 说明 | 认证方式 |
|--------|------|----------|
| 所有者流（Owner） | 注册用户登录后管理自己的文件、分享、回收站等 | JWT（Access Token + Refresh Token） |
| 访客流（Visitor） | 通过分享链接访问他人文件，无需注册登录 | 分享令牌（Share Token） |
| 管理员流（Admin） | 管理员用户登录后进入独立管理后台 | JWT（Access Token + Refresh Token） |

三个产品流对应四个 Shell：Auth Shell（认证前）、Owner Shell（所有者主界面）、Visitor Shell（访客界面）、Admin Shell（管理后台）。同一时刻只有一个 Shell 处于活跃状态。

### 1.2 文档约定

- 功能 ID 沿用桌面端旧编号体系（O-01 ~ O-29、V-01 ~ V-04），便于跨端追踪对照
- 对应页面使用 Web 端路由路径表示
- API 端点只标注路由，不展开请求/响应参数（详见 Task 2）
- 优先级分为 P0（核心）、P1（重要）、P2（次要）三档

|--------|----------|----------|---------|--------|------|

### 2.2 文件资源管理器模块

文件资源管理器是 Web 客户端的核心页面，采用三栏布局：左侧目录树 + 中间文件列表 + 右侧详情面板（可选）。文件视图模式（我的文件、已共享、回收站）在同一页面内通过路由参数或状态切换，不离开资源管理器上下文。

| 功能ID | 功能名称 | 对应页面 | API端点 | 优先级 | 备注 |
|--------|----------|----------|---------|--------|------|
| O-05 | 文件浏览 | `/drive`（默认 `/drive/myfiles`） | `GET /api/file/list` | P0 | 分页加载，支持排序和类型筛选；文件夹钻取通过路由参数 `?folderId=` 实现 |
| O-06 | 文件详情 | `/drive`（详情侧栏/弹窗） | `GET /api/file/{file_id}` | P1 | 点击文件项展示元信息面板 |
| O-07 | 文件搜索 | `/drive`（顶部搜索栏） | `GET /api/file/search` | P0 | 文件名模糊搜索，支持按类型和目录范围筛选 |
| O-08 | 文件上传 | `/drive`（上传按钮/拖拽区域） | `POST /api/file/upload/init`<br>`POST /api/file/upload/chunk`<br>`POST /api/file/upload/complete` | P0 | 5MB 分片上传，支持断点续传和秒传；上传进度在传输中心展示 |
| O-09 | 文件下载 | `/drive`（行内下载按钮） | `GET /api/file/download/{file_id}/info`<br>`GET /api/file/download/{file_id}` | P0 | 支持 HTTP Range 断点续传；浏览器原生下载或 Axios 流式下载 |
| O-10 | 重命名 | `/drive`（行内/右键菜单） | `PUT /api/file/{file_id}/rename` | P0 | 文件或文件夹重命名，校验同名冲突 |
| O-11 | 移动 | `/drive`（工具栏/右键菜单） | `PUT /api/file/move` | P0 | 批量移动，支持选择目标目录（目录树弹窗） |
| O-12 | 复制 | `/drive`（工具栏/右键菜单） | `POST /api/file/copy` | P0 | 批量复制，同目录自动加后缀避免冲突 |
| O-13 | 删除 | `/drive`（工具栏/右键菜单） | `DELETE /api/file` | P0 | 批量软删除到回收站 |
| O-14 | 创建文件夹 | `/drive`（新建按钮） | `POST /api/folder/create` | P0 | 在当前目录创建文件夹，校验同级重名 |
| O-15 | 目录树 | `/drive`（左侧边栏/移动弹窗） | `GET /api/folder/tree` | P0 | 左侧常驻目录树面板，支持展开/折叠；移动时作为目标选择器 |
| O-16 | 面包屑 | `/drive`（顶部路径导航） | `GET /api/folder/{folder_id}/breadcrumb` | P0 | 点击面包屑项可跳转到对应目录 |

## 3. 功能映射表（Visitor V-01 ~ V-04）

访客流运行在独立的 Visitor Shell 中，不依赖所有者登录，不共享 Owner Shell 的导航结构。

| 功能ID | 功能名称 | 对应页面 | API端点 | 优先级 | 备注 |
|--------|----------|----------|---------|--------|------|

| V-02 | 分享验证 | `/s/{share_id}` | `POST /api/share/access/{share_id}` | P0 | 如有密码保护则展示密码输入框；验证通过后获取 Share Token 存入内存 |

## 4. 功能映射表（Admin）

管理员流运行在独立的 Admin Shell 中，登录后根据 JWT 中的 `role === 1` 自动路由进入。Admin Shell 不包含普通用户文件浏览功能。

| 功能ID | 功能名称 | 对应页面 | API端点 | 优先级 | 备注 |
|--------|----------|----------|---------|--------|------|
| A-01 | 用户列表 | `/admin/users` | `GET /api/admin/users` | P0 | 分页搜索，支持按用户名/邮箱搜索、状态筛选、角色筛选 |
| A-02 | 用户详情 | `/admin/users`（详情弹窗/抽屉） | `GET /api/admin/users/{id}` | P0 | 展示用户基础信息、已用空间、配额、文件数 |
| A-03 | 变更用户状态 | `/admin/users`（行内开关） | `PUT /api/admin/users/{id}/status` | P0 | 正常/禁用切换 |
| A-04 | 变更用户角色 | `/admin/users`（行内下拉） | `PUT /api/admin/users/{id}/role` | P0 | 普通用户/管理员切换；禁止修改自己的角色 |
| A-05 | 删除用户 | `/admin/users`（行内按钮） | `DELETE /api/admin/users/{id}` | P0 | 软删除用户；禁止删除最后一个管理员；需二次确认 |
| A-06 | 分享列表 | `/admin/shares` | `GET /api/admin/shares` | P0 | 分页搜索，支持按分享ID/创建者搜索、状态筛选 |
| A-07 | 分享详情 | `/admin/shares`（详情弹窗） | `GET /api/admin/shares/{id}` | P1 | 展示分享基础信息和关联文件列表 |
| A-08 | 强制取消分享 | `/admin/shares`（行内按钮） | `DELETE /api/admin/shares/{id}` | P0 | 管理员强制取消任意分享；需二次确认 |
| A-09 | 操作日志 | `/admin/logs` | `GET /api/logs` | P1 | 分页查看系统操作日志，支持按操作类型和时间范围筛选 |
| A-10 | 概览统计 | `/admin/system` | `GET /api/admin/stats/overview` | P0 | 总用户数、总文件数、总存储空间、存储使用率卡片 |
| A-11 | 系统状态 | `/admin/system` | `GET /api/admin/stats/system` | P0 | 版本信息、运行时间、数据库状态、Redis 状态 |
| A-12 | 全局存储统计 | `/admin/system` | `GET /api/admin/storage/stats` | P1 | 全局存储分布和占用统计 |

## 5. 优先级划分

### 5.1 P0 — 核心功能（首版必须实现）

P0 功能构成 Web 客户端的最小可用产品（MVP），缺失任何一项都会导致核心用户流程断裂。

**认证模块**：O-01（注册）、O-02（登录）、O-03（令牌刷新）、O-04（登出）
**文件资源管理器**：O-05（文件浏览）、O-07（搜索）、O-08（上传）、O-09（下载）、O-10（重命名）、O-11（移动）、O-12（复制）、O-13（删除）、O-14（创建文件夹）、O-15（目录树）、O-16（面包屑）
**分享管理**：O-17（创建分享）、O-18（分享列表）、O-21（取消分享）
**回收站**：O-22（回收站列表）、O-23（恢复）、O-24（彻底删除）、O-25（清空回收站）
**用户中心**：O-26（个人信息查看）、O-27（修改资料）、O-28（修改密码）、O-29（存储统计）
**访客**：V-01（打开分享）、V-02（分享验证）、V-03（浏览分享）、V-04（下载分享文件）
**管理员**：A-01（用户列表）、A-02（用户详情）、A-03（变更状态）、A-04（变更角色）、A-05（删除用户）、A-06（分享列表）、A-08（强制取消分享）、A-10（概览统计）、A-11（系统状态）

### 5.2 P1 — 重要功能（首版建议实现）

P1 功能显著提升用户体验，但缺失不会阻断核心流程。

**文件资源管理器**：O-06（文件详情侧栏）
**分享管理**：O-19（分享详情）、O-20（更新分享）
**传输中心**：O-08-O（上传任务管理）、O-09-O（下载任务管理）
**管理员**：A-07（分享详情）、A-09（操作日志）、A-12（全局存储统计）

### 5.3 P2 — 次要功能（后续迭代实现）

P2 功能属于体验优化或边缘场景，可在后续版本中补充。

- 文件预览（图片/文档/视频在线预览）
- 批量操作的高级交互（Shift 连选、Ctrl 多选优化）
- 拖拽上传的视觉效果增强
- 主题切换（深色模式）
- 键盘快捷键支持
- 操作日志的用户侧查看（非管理员）

## 6. 排除项清单

以下功能明确排除在 Web 客户端首版范围之外：

| 功能 | 排除理由 | 后续可能性 |
|------|----------|-----------|
| 离线同步 | 需要 Service Worker、本地 IndexedDB 缓存和冲突解决策略 | 低，Web 端以在线使用为主 |
| 实时通知（WebSocket/SSE） | 后端尚无推送能力 | 中，待后端支持后可接入 |
| 预览引擎 | 文档/图片/视频预览需专用渲染组件或第三方服务 | 中，P2 规划 |
| 版本历史 | 后端不支持文件版本管理 | 低，依赖后端能力 |
| 协同编辑 | 需 OT/CRDT 算法和实时协作服务 | 低，超出网盘基础功能范围 |
| 多账户同时在线 | 首版仅支持单账户登录 | 低，Web 端单账户已满足主流需求 |
| 系统托盘集成 | Web 端无系统托盘概念 | 不适用 |
| 自动更新 | Web 端通过部署即更新，无需内置机制 | 不适用 |
| 国际化（i18n） | 首版仅中文界面 | 中，后续可接入 vue-i18n |
| 拖拽上传 | 首版使用文件选择对话框上传；拖拽可作为 P2 增强 | 中，P2 规划 |
| 移动端适配 | 目标平台仅为桌面浏览器（最小 1366x768） | 低，需独立设计移动端方案 |
| 第三方登录（OAuth） | 后端当前仅支持用户名/邮箱密码登录 | 低，依赖后端支持 |

## 7. 页面路由总览

| 路由路径 | 所属 Shell | 说明 |
|----------|-----------|------|
| `/auth/login` | Auth Shell | 登录页 |
| `/auth/register` | Auth Shell | 注册页 |
| `/drive` | Owner Shell | 文件资源管理器首页，默认重定向到 `/drive/myfiles` |
| `/drive/myfiles` | Owner Shell | 我的文件视图 |
| `/drive/shared` | Owner Shell | 已共享视图（分享列表） |
| `/drive/trash` | Owner Shell | 回收站视图 |
| `/shares` | Owner Shell | 分享管理页面（与 `/drive/shared` 为同一功能的不同入口） |
| `/transfers` | Owner Shell | 传输中心 |
| `/settings/profile` | Owner Shell | 个人资料设置 |
| `/settings/security` | Owner Shell | 安全设置（修改密码） |
| `/settings/storage` | Owner Shell | 存储统计 |
| `/s/:shareId` | Visitor Shell | 分享访问/浏览页 |
| `/admin/users` | Admin Shell | 用户管理 |
| `/admin/shares` | Admin Shell | 分享管理 |
| `/admin/logs` | Admin Shell | 操作日志 |
| `/admin/system` | Admin Shell | 系统监控 |

> 注：`/drive/myfiles`、`/drive/shared`、`/drive/trash` 共享同一个资源管理器页面组件，通过路由参数切换视图模式，与桌面端 `DriveBrowserPage` 内的 `VIEW-MYFILES` / `VIEW-SHARED` / `VIEW-TRASH` 设计思想一致。
